## 0. 开始前：三个必须先确认的点

🔴 这三点没确认就提交，大概率被驳回重排一周。

### 0.1 营业执照上有没有「字号」？

河北管局的规则：**个体工商户有字号的选「企业」，没有字号的选「个人」，并在备注写明「个体工商户无工商字号」**。

| 执照长什么样 | 备案时主体类型 | 备注 |
|---|---|---|
| 名称是「唐山市XX科技服务部」「XX工作室」这类 | **企业** | 按执照全称填，一字不能差 |
| 名称就是你本人姓名 | **个人** | 必须备注「个体工商户无工商字号」 |

👉 **现在就看一眼执照，记住是哪种。**

### 0.2 服务器是否满足备案条件

- 必须是中国大陆地域（北京/上海/杭州/张家口等），**香港、海外不行**
- 必须**包年包月**，且**剩余时长 ≥ 3 个月**（按量付费的实例不能备案）
- 备案必须在**服务器所在的那个云账号**下提交（谁的服务器谁备案）

> 若服务器与备案账号不是同一个阿里云账号，需要先获取「备案服务码」；同账号则无需单独获取。

### 0.3 域名状态

- `sunfocused.top` 已完成**实名认证**，且持有者 = 个体工商户（或经营者本人）
- 有效期 **> 3 个月**（不足就先续费，否则系统直接卡住）

## 2. 八步流程

```
① 登录阿里云 ICP 代备案系统（beian.aliyun.com）→「开始备案」
        ↓
② 基础信息校验：填域名 + 服务器 IP，系统自动校验资格
        ↓
③ 填写主办者信息（个体工商户）
        ↓
④ 填写网站信息（★最容易错，见 §3）
        ↓
⑤ 上传资料 + 人脸核验
        ↓
⑥ 确认信息 → 提交订单
        ↓
⑦ 阿里云初审（1–2 工作日，会打电话，务必接听）
        ↓
⑧ 工信部短信核验（24 小时内完成，超时自动退回）
        ↓
⑨ 河北省管局审核（7–10 工作日）
        ↓
⑩ 收到备案号 → 才能配解析、开通网站
```

🔴 **第 ⑨ 步之前，域名绝对不能解析、网站绝对不能对外开放。** 河北管局明确要求「未备案成功的网站必须关闭状态，如开放可能会被管局退回」。

## 3. 填表逐项指南（决定成败的三项）

### 3.1 网站名称

**建议填：`小小葵番茄钟官网`**

硬性禁区：
- ❌ 不能含「中国」「国家」「政府」「中华」
- ❌ 不能含需要前置审批的行业词：金融、医疗、药品、教育、新闻、出版、游戏
- ❌ 不能是纯姓名、纯数字
- ❌ 不能与知名品牌重名

> 产品名「小小葵番茄钟」是自有品牌，不含敏感词，加「官网」两字最稳。
> ⚠️ 不要写成「小小葵番茄钟商城」「XX 软件销售」——「商城」「销售」会触发经营性审查。

### 3.2 服务内容（下拉勾选）

**勾：`企业门户 / 信息展示`**

🔴 **绝对不要勾「网络购物」「在线交易」「电子商务」**——这三项会触发《增值电信业务经营许可证》（ICP 许可证）要求，那个门槛是注册资本 100 万起，个体户办不下来。

### 3.3 网站简介 / 备注

**直接可用：**

```
本站为小小葵番茄钟（个体工商户）的官方产品网站，主要展示产品功能介绍、
使用说明、隐私政策与服务条款，并提供 Android 版安装包的官方下载。
网站面向家长用户提供产品信息浏览服务。
```

三条纪律：
1. 简介必须与勾选的服务内容一致（勾「信息展示」就别写「在线商城」）
2. 简介必须与网站真实内容一致（审核会打开看）
3. **不要主动写「在线支付」「在线购买」字样**

### 3.4 前置审批

**选「无」。** 番茄钟属效率工具，不在新闻/出版/教育/医疗/药品/文化/广播影视等前置审批范围内。

> 注意：App 是给儿童用的效率工具，但备案类目上不是「教育培训」，不要自己往教育类上靠——那会触发教育移动应用备案。

## 6. 备案通过后必做的三件事

### 6.1 配解析 + 开站（此时才能开放）

```
① 域名解析：A 记录 → 服务器公网 IP
② Nginx 加站点配置（详见 `docs/官网双域名分流_技术评审_v1.md`）
③ 申请 SSL 证书（此时才能用 HTTP-01 验证，之前只能走 DNS-01）
④ 部署网站内容
```

### 6.2 页脚悬挂备案号（强制）

页面底部显示：`冀ICP备XXXXXXXX号-1`，并**链接到** `https://beian.miit.gov.cn`。

不挂会被抽查处罚，这是明确的驳回/整改理由。

### 6.3 30 日内完成公安联网备案（最容易漏）

| 项 | 内容 |
|---|---|
| 去哪办 | 「全国互联网安全管理服务平台」 |
| 时限 | 网站开通后 **30 日内** |
| 前置 | ICP 备案必须先完成 |
| 通过后 | 也会拿到一个公安备案号，同样挂页脚 |

## 7. 一条必须知情的边界

备案时勾「企业门户/信息展示」，但网站实际会承载购买功能。这中间有一个客观存在的张力：

- **不勾经营性**：因为《电信业务经营许可管理办法》之外，多省通管局明确「自营销售自有软件不属于增值电信业务」，不需要 ICP 许可证；
- **但管局核查时**，如果认为你从事在线交易，可能要求补办许可证或整改。

**降低风险的两条做法：**

1. **站点内容以「产品介绍 + 免费下载 + 激活码激活」为主线**，购买环节走激活码授权（即用户在自己站点完成解锁授权），而不是做成「电商购物车 + 在线下单支付」的形态。这与本产品的实际交付方式一致；
2. 若后续确实要做 App 内在线支付，再评估是否走「变更备案」增加经营类目。

> 结论：按「信息展示」备案是当前合理选择，但请知悉这层边界，不要主动在简介里写「在线销售」「电商」字样。
