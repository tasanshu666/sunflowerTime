# 动画 / 动态视频提示词清单 v1（豆包 · 图生视频）

> **用途**：给「向日葵专注」App 各场景配动态素材，或做短视频引流素材。
> **性质**：**美术素材提示词草稿，待玄参大人确认**。不改 PRD、不定玩法，仅把已有文档/代码里已定的画面语义翻译成可粘贴的生成提示词。
> **依据**：`向日葵专注_PRD_v2.0.md` §4.1（打盹屏 + 四档反馈）、§4.1.2（结算动画）、§4.5（任务/完美日）、§4.6（花园/植物）、§4.9（夸夸台）；代码 `lib/presentation/child/**` 实地核对。
> **统一参考图**：用户提供的卡通风盆栽向日葵（奶黄纯色背景、粗描边、圆润花瓣、笑脸、陶土盆）。
> 状态：待确认后开工。

## 0. 全局风格约束（每一段提示词都建议带上）

**产品红线（来自 PRD §1.4、§4.1.1，写提示词时必须守住）**

| 红线 | 提示词里的对应写法 |
|---|---|
| 是工具不是游戏，语言用「陪伴 / 训练 / 养成」 | 禁止出现「游戏、关卡、战斗、胜利、炫酷特效」等词 |
| 低打扰、无声为主 | 禁止镜头运动（推拉摇移）、禁止闪烁、禁止任何突然变化 |
| 专注中「可瞟不可盯」 | 专注页全程 **零突事件**：只有呼吸式明暗 + 极慢姿态 |
| 表演式庆祝只留给结算 | 其他场景的动效必须**明显弱于结算**，防反向激励 |

**统一风格句（复制到每段提示词开头）**

> 沿用参考图的卡通插画风格：粗描边、圆润造型、暖黄色系（向日葵 #FFC93C / #FFA726，盆 #E0762F，背景奶黄 #FFF3C4），平涂上色，无渐变噪点，无文字无水印。

**通用技术约束**

- 画面里**只保留 1~2 处动态**，其余全部静止 → 这是能过审、且不会「抢注意力」的关键。
- 结尾加：`全程无镜头移动、无闪烁、无跳变，动作极缓，可作为无缝循环素材。`
- 首次生成若动作过猛，把「极慢 / 微弱 / 缓缓」再加一层限定词，必要时降低运动幅度描述。

**比例速查（很重要，横竖屏别搞错）**

| 场景 | 屏幕方向 | 建议比例 |
|---|---|---|
| 专注页（打盹屏）、结算页 | **横屏** | 16:9 |
| 首页 / 花园 / 商店 / 任务卡 / 夸夸台 | 竖屏 | 9:16 |
| 短视频引流 | 竖屏 | 9:16（可加 3:4 备选） |

## A. 专注闭环（核心，5 段）

### A1 · 专注页 · 常态陪伴（打盹屏主体）★已交付

**场景**：孩子横放手机开始专注后，整个时长里循环播放的底图。
**依据**：PRD §4.1.1「低亮 · 慢频 · 零突事件」「中央是那朵在做自己的事的向日葵」；§4.1.3 一档。

> 这是一张可爱卡通风的盆栽向日葵插画：圆润花瓣、憨态笑脸、陶土色花盆、柔和奶黄色背景。请基于此图生成一段治愈系循环动画，表现它「安安静静做自己的事」的状态：
>
> 整体低亮、缓慢、极其安静，像一盏温柔的小夜灯。向日葵做非常轻微的呼吸式明暗起伏，花头以极慢速度小幅度左右轻摆，仿佛在低头忙自己的活；叶片偶尔极轻微颤动。开场时缓缓抬起花头，朝镜头安静看一眼（约 1 秒），随后低头继续「忙碌」，之后不再与观众对视。
>
> 每隔一段时间，从花朵旁缓缓浮出一粒小小的温暖光点，光点慢悠悠飘向画面边缘、渐渐淡出，像它整理好一缕阳光送出去。
>
> 背景保持纯色不变，呼吸明暗与光点是画面中仅有的动态。全程无突然动作、无跳动、节奏极舒缓，可无缝循环，保持原图风格与构图。

**规格**：16:9，8~10 秒循环。
**可选拆分**：若要代码里分别播「开场抬头」与「常态循环」，把抬头那句单独出一段 3 秒的。

### A2 · 专注页 · 随光报信（二档 · 每 1/3 进度触发一次）

**场景**：进度走到 1/3、2/3 时弹一次，全屏叠加在底图之上。
**依据**：PRD §4.1.3 二档「往外送出一粒光（朝屏外走）+ 一句极轻气泡，同一拍只此一个动作」；文案固定「我去把它放好。」

> 参考图同款卡通盆栽向日葵，奶黄纯色背景。表演一个非常轻的小动作：向日葵轻轻抬眼，从花心旁缓缓浮出一粒明亮的金色小光点；光点沿画面右侧（或上方）慢悠悠飘出，越飞越淡，直至消失在画面边缘。整个过程中向日葵只是安静地目送，身体几乎没有移动，只有一个极轻的、微微上抬的姿态。
>
> 动作幅度极小、极慢，全程约 4 秒，无镜头移动、无闪烁，光点是画面里唯一的运动元素，保持原图卡通描边风格与配色。

**规格**：16:9，4 秒，建议 **带透明通道**（叠加用）或纯色背景可抠。
**注意**：气泡文案（「我去把它放好。」）建议**由 App 代码绘制**，不要烧进视频里——文案以后可能改。

### A3 · 专注页 · 欢迎回来（三档）

**场景**：孩子中途离席后亮屏回来，播一次。
**依据**：PRD §4.1.3 三档「最轻的一道光晕 / 半秒眨眼」，**纯视觉无声**。

> 参考图同款卡通盆栽向日葵，奶黄纯色背景。向日葵先安静低头做自己的事，随后眼睛轻轻眨了一下（约半秒），与此同时身体四周浮现一圈非常柔和、非常淡的暖黄色光晕，光晕由内向外缓缓扩散并渐渐淡去。整个动作只有眨眼与光晕两件事，全程约 3 秒，幅度极轻，没有任何跳跃、闪屏或镜头运动，温暖安静，保持原图风格。

**规格**：16:9，3 秒。
**关键**：**绝不能做得比结算动画更热闹**（PRD §4.1.3 第 3 条「主菜留白」）。

### A4 · 专注页 · 唤醒提醒（四档 · 离席超阈值）

**场景**：离席超过阈值时，配合语音提示出现的画面。
**依据**：PRD §4.1.3 四档「睁眼说一句软话」；台词「向日葵想你了，回来看看吧」→「休息一下就回来哦」。

> 参考图同款卡通盆栽向日葵，奶黄纯色背景。向日葵缓缓睁开原本闭着的眼睛，抬头望向镜头，神情温和而关切，像在轻轻呼唤一个走开的朋友；嘴部有极轻微的说话起伏。动作缓慢温柔，全程约 3 秒，无急促动作、无闪烁、无镜头运动，不显责备，只有温柔的期待，保持原图卡通风格与配色。

**规格**：16:9，3 秒，配合语音（语音由 App 侧播放，不烧进视频）。

### A5 · 结算页 · 光回罐 + 醒着庆祝 ★全场视觉高光

**场景**：专注倒计时结束、自动结算时播放。PRD 明写「**结算动画是全场的视觉高光，设计上要精彩**」。
**依据**：PRD §4.1.2 第 5 条「那束出远门的光从屏外回来、落进阳光罐，账同步上涨；本次专注时长、产出阳光数、当日累计、向日葵醒着庆祝」。

> 参考图同款卡通盆栽向日葵，但此刻它是**完全清醒、精神饱满**的状态，画面明亮温暖。场景是两张对照画面：先是那束走了很远的光——一粒明亮的金色光点——从画面外缓缓飞回，越来越亮，最后轻轻落进画面一侧的一只透明阳光玻璃罐里；罐中随即亮起、微微上浮。接着向日葵完全睁开眼睛，花头扬起、花瓣全面张开，是开心的「醒着庆祝」：轻轻摇晃两三下、露出灿烂笑容、脸颊泛红，身体四周散出几粒细小星光缓缓上浮。
>
> 整体温暖明亮、有仪式感但不过分喧闹，全程约 5~6 秒，动作为「光飞回 → 落入罐中 → 向日葵苏醒庆祝」，节奏清晰、可循环结尾一帧，保持原图卡通描边风格与暖黄配色。无需任何文字。

**规格**：16:9，5~6 秒。这是最值得多跑几版、精修的一段。
**注意**：数字滚动（时长 / 阳光数 / 累计）必须由 **App 代码**渲染，**不要生成进视频**，否则和真实数据对不上。

### C6 · 花谢循环（盛开 → 回落休整）

**依据**：成株盛开保持 3 天后花谢（`kBloomDurationDays`），进度回落到 0.5，由时间/养护重新养满后再度盛开；体型不回缩（项目记忆「植物养成·花谢循环」）。

> 参考图同款卡通插画风格，浅色背景，主体居中。盛开的向日葵花瓣先是极轻微地颤动，随后一片片缓缓向内收拢、微微垂下，花心光泽柔和地暗下去，整株植物保持原有高度但进入安静的休整状态；最后一片花瓣落下时，茎叶轻轻晃了一下便静止。氛围是从容、安静、有余地的，不是枯萎也不悲伤，全程约 4 秒，无镜头运动、无闪烁，保持原图粗描边卡通风格。

**规格**：1:1，4 秒。
**注意**：**不能有「凋零感 / 悲剧感」**——这是设计上的可循环休整，不是惩罚。

### C7 · 枯萎与救回（两段，建议做成一对）

**依据**：植物 `wilting` → 浇水/施肥后恢复 `growing`。

**(a) 枯萎（状态恶化）**

> 参考图同款卡通插画风格，浅色背景。原本健康的小植物叶片与花瓣逐渐失去光泽、颜色变淡发黄，茎秆缓缓向下弯曲，花头低垂，整体显得无精打采；土面显出干裂的细纹。过程缓慢但有明显的「没精神」感，全程约 4 秒，无镜头运动、无闪烁，颜色不要灰败死气（要留可救回的余地），保持原图粗描边卡通风格。

**(b) 救回（恢复健康）**

## 附二、生成与验收注意事项

1. **数字与文字一律不烧进视频**（时长、阳光数、任务名、气泡台词、牌子字），全部由 App 代码绘制 —— 否则数据一变就对不上，也会出现中文乱码。
2. **专注页必须横屏 16:9，其余场景竖屏 9:16** —— 打盹屏是横屏的，出成竖屏会用不了。
3. **验收看两条**：① 呼吸/摆动幅度是否足够轻（太亮太动就违背「可瞟不可盯」）；② 光点是否「慢悠悠」（速度是这类动画的灵魂）。
4. **反向激励检查**：拿所有动画与 A5 结算动画并排看一遍，任何一段若比结算更热闹，就要调弱 —— PRD 明确禁止「故意走神只为看朋友醒来说话」。
5. **循环素材**：结尾帧尽量接近开头帧，方便 `AnimatedBuilder` 或视频播放器无缝循环。
6. **素材可用性提醒**：上述视频若用于 App 内播放，需要 Flutter 侧支持（`video_player` 或序列帧）。**是否采用动画素材、以什么形式接入，属于产品与工程决策，本清单只提供提示词，不代表已排期**。
