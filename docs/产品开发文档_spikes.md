## 1. S1 · 四档反馈 + 向日葵画布（原 T08）

### 1.1 需求对齐（PRD §4.1.1 / §4.1.3）
- 中央那朵"在做自己事的花"，慢而不突、零突事件（打盹屏基调）。
- 四档反馈：① 常态产光 ② 随光报信（每 1/3 进度送一粒光 + 气泡，不夸奖）③ 欢迎回来（离席恢复，纯视觉）④ 唤醒提醒（离席超时，睁眼说软话，语音占位）。
- 台词三原则：随光只报信不夸奖；夸奖只留结算动画与家长转述；任何一档不得比结算动画更诱人。

### 1.2 交付物
- `sunflower_canvas.dart`：CustomPainter 绘制 + 4s 呼吸动画，按档位绘制光晕/花瓣/花心/睁眼/送光粒子。
- `feedback_overlay.dart`：仅二档/四档出气泡，文案已按三原则落地。
- `s1_demo_page.dart`：一屏四档切换预览（**仅 spike 用，非产品页**；产品页为打盹屏，四档由专注引擎按触发自动呈现）。

### 1.3 验收与状态
| 验收项 | 标准 | 状态 |
|---|---|---|
| 四档切换无卡顿 | 真机流畅 | ⏳ 待真机（本机无 JDK/模拟器） |
| 向日葵绘制帧率达标 | 真机目测流畅 | ⏳ 待真机 |
| 台词三原则 | 已代码落地 | ✅ 已符合 |

## 2. S2 · 兑换服务纯逻辑（原 T13）

### 2.1 需求对齐（PRD §4.8 / 口径裁定 C5）
- 兑换申请状态机：`pending`（待核销）/ `queued`（排队）/ `verified`（自动放行）。
- 免确认双条件（C5）：① 单笔价 ≤ 高 130 / 低 50；② 当月累计自动放行 ≤ 月池×25%，且上限 = min(固定天花板 100/40, 月池×25%)；③ 自服务类一律不自动放行。

### 2.2 交付物
- `redemption_service.dart`：`RedemptionService.decide()` 纯函数 + `RedemptionDecision` 结果对象。
- 边界覆盖：单笔候选阈值 vs 实际天花板、月度自动子限额、整体池余量双闸、自服务类豁免、排队不拒绝。

### 2.3 验收与状态
| 验收项 | 标准 | 状态 |
|---|---|---|
| 免确认双条件符合 C5 | 公式一致 | ✅ 代码落地 + 单测覆盖 |
| 月度池上限公式 | `min(100/40, 月池×25%)` | ✅ 13/13 单测通过 |
| 边界单测覆盖 | 单测存在 | ✅ 13 用例全过（`dart test`） |

> ⚠️ **待裁定**：C5 正文"池=200 时低年段降到 20"，但公式 `min(40, 200×25%)=40` 给 40。实现按**公式 40**，已在代码注释与测试标记待确认，需玄参大人拍板。
