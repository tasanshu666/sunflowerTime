## 1. 技术架构

### 1.1 分层（单向依赖）

```
domain（纯业务，84 文件）
  ↑
data/local（Drift + SQLCipher，30 文件）
  ↑
presentation（UI + Riverpod，115 文件）
```
辅助层：`core`（28，常量/工具）、`shared`（8，响应式/主题）、`platform`（4，音频/系统）、`l10n`（3，ARB）

### 1.2 关键技术选型

| 关注点 | 方案 |
|---|---|
| 状态管理 | Riverpod（provider 分层，跨孩子切换靠 `childProfileRevisionProvider`） |
| 本地库 | Drift + SQLCipher（DB 口令**运行期三段拼装**，不落明文） |
| 音频 | `just_audio`（物种专属 → 通用兜底两级回退；许愿树独立 AudioPlayer） |
| 内购 | `in_app_purchase`（iOS 一次性买断；Android IAP **搁置**） |
| 安全 | iOS `--obfuscate --split-debug-info`；DB 口令拼装；不做 JWS 本地验签/第三方壳 |
| 本地化 | ARB（zh / en），英文 1.3× 字号无障碍场景有专项探针 |

### 1.3 硬约束（改动前必读）

- `schemaVersion = 32` 不得擅动；加索引须 `DROP INDEX IF EXISTS` → `createAll()`（drift 已知坑）
- 孩子端 5 tab：Today / Growth / Garden / Store / Mine（**无 My tab**）
- 无通用 `spend()`；禁止给 `SunlightRepository` 加方法
- 版本号两处同源：`pubspec.yaml` + `app_constants.dart kAppBuildNumber`，有守卫用例
- 历史文档留痕不抹除（设计快照/裁定判例按纪律不回改）
