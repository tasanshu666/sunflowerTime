## 0. 三句话结论

1. **可以先走 APP 备案，不必等软著、不必等刻章。** App 备案与网站备案是**并列的两套系统**（阿里云官方原文：「App备案与网站备案为并列关系，无需先完成网站备案即可直接提交App备案申请」），与软著也**无前后依赖**。App 备案是**商店提审的前置**，软著也是商店提审的前置 —— 两个前置**并行跑**，谁先下证谁先用。
2. **河北个体户做 App 备案，不需要公章。** 依据有二：① 华为云《ICP备案-河北管局要求:企业用户》原文：「互联网信息服务负责人与主体负责人无需保持一致(无需是法人)，**无授权书要求**」→ 让**王政**做主体负责人、**玄参本人**做 App 负责人；② 《各省个体工商户ICP备案要求》河北行：「均以企业名义备案……**没有公章的核验单可以不用盖章，接入商做好相应备注**」。全程无盖章环节。（这与软著不同：软著机构实名认证强制要盖章授权书，所以软著必须等章。）
3. **「域名备案是我个人的」不影响 App 备案的提交资格**，但会影响**填表方式**：App 备案若填入 `sunfocused.cn`，会触发域名核验 → 域名持有者（个人）≠ 备案主体（个体户）→ **驳回**。纯本地 App 的正解是**域名栏不填任何域名**（详见 §4.3）。

### 2.3 🔴 域名栏的正确填法（核心）

阿里云「填写App信息」表单里，域名相关字段分三层，**不是每一层都要填**：

| 字段 | 我们的填法 | 理由 |
|---|---|---|
| **App 全部后台服务域名** | **留空 / 填「无」** | 本 App 纯本地单机，**无后台服务器**，无任何 API 域名。阿里云该字段语义 = 「App 启动运行时连接后台服务器所使用的域名」—— 我们没有后台 → 无此项。触发填写强制时，在备注注明「纯本地单机应用，无后台服务域名」。 |
| **接入阿里云服务器的域名** | 随接入信息自动带出；若强制要求 → 见下方「降级方案」 | 该字段属接入信息，用于挂服务器 |
| **具体使用的域名**（运行平台内） | **留空 / 填「无」** | 同上 |

> 🔴 **降级方案（若系统强制要求填域名）**：
> ① 域名 `sunfocused.cn` 过户到个体工商户（3–5 工作日，.cn 任何持有者信息改动都需重新实名）；
> ② 注销现有**个人**主体网站备案（⚠️ 注销期间域名不可访问 → 隐私政策 404 → **iOS 2105 已上架版本的隐私政策链接会挂**，需临时在 App 内提供内嵌版隐私政策兜底）；
> ③ 在个体户主体下**一次性提交「网站备案 + App 备案」**（阿里云支持一个订单同时做两者）。
>
> **这条降级路径代价不小，只在主路径走不通时启用。**

## 3. 阿里云账号与服务器接入（v2 修订 · 三方案对比）

> 🔴 **v2 修订说明（2026-11-11）**：v1 版的硬约束表述**有错**。v1 写「一个服务器只能备案一个主体 → 必须再买一台」，这是**误读**：阿里云官方原文是「一个服务器的公网IP，可支持绑定 **5 个**备案服务号，供您完成 **5 次**网站备案」且「5 个网站备案可为同一个备案主体下，**也可以是不同的备案主体，最多可对应五个不同主体**」。
>
> **结论：现有服务器没有白买，它的 5 个备案额度里，1 个已用于个人主体网站备案，**还剩 4 个**。**
>
> v1 真正的错误是：把「**跨账号授权**的资格门槛」误当成了「服务器额度不够」。真实卡点见 §3.1 第 2 条。

### 3.1 三条硬约束（全部官方原文，可复核）

| # | 约束 | 官方原文 | 对我们的含义 |
|---|---|---|---|
| 1 | **一个账号一套备案主体资料** | 「备案时一个账号只能备案一个主体相关信息」；「一个阿里云账号只能备案一个主体（公司或个人）信息。如果您之前备案过，需使用之前备案的阿里云账号登录阿里云ICP代备案管理系统提交备案订单」 | 现账号 A 已挂着**个人主体**（京ICP备2026070040号-1）→ **不能**在 A 下并存第二套「个体工商户主体」资料 |
| 2 | 🔴 **跨账号授权的资格门槛** | 阿里云备案服务码策略公告（2024-10-10）：「云产品购买账号与备案账号不一致：**仅企业(不含个体工商户)认证的账号**，其云产品可用于业务相关账号备案」「**个人/个体工商户认证账号，其云产品仅能用于本账号备案**」 | 官方《备案服务器检查》原文：「**一台服务器可以备案多个主体吗？可以，但是不同主体需要备案在多个阿里云账号下**。服务器所在账号必须完成企业实名认证(**不含个体工商户**)」⇒ **个体户账号无法把服务器授权给别的账号**；个人认证账号同样无授权资格 |
| 3 | **ICP 备案不跨省变更主体** | 「ICP备案不支持跨省变更主体，部分省市管局不允许个人变更为企业」；北京管局规则：「**个人备案不可以变更为其他个人或单位备案**」 | 「把个人主体转给王政」**不能直接转**，只有 §3.3 / §3.4 两条路 |

> 💡 **第 2 条是全局关键**：既然**个体户认证账号的云产品只能用于本账号**，那么「个体户主体用现有服务器」的唯一合法形态就是——**让个体户主体成为现有账号下的那套主体资料**，即账号认证变更 + 注销旧个人主体后重做（§3.3）。
>
> 🟢 **反过来说**：个体户账号下**自己**的服务器，可以给**自己**备案（同一账号、无需授权）。所以「个体户新账号 + 该账号下自己的服务器」是天然成立的（§3.2）。

### 3.2 方案 A（推荐）：个体户新账号 + 该账号下新购云服务器

> 🔴 **两件事必须分开：账号「注册」≠ 账号「实名认证」。**
> - **注册** = 手机号 + 密码，**谁操作都行**，不需要任何证件、不需要王政配合、不需要营业执照。
> - **实名认证** = 把账号归属绑定到「个体户」这个主体上，**这一步才需要王政的身份证和执照**，且大概率需要王政本人配合一次刷脸/支付宝授权。

```
① 注册新账号（玄参自己手机号即可）────────── 5 分钟
      ↓
② 个体户企业实名认证（执照 + 王政身份证 + 王政支付宝）── 30 分钟～3 工作日
      ↓
③ 该账号下新购云服务器（境内 2核2G，包年包月 ≥3 个月）→ 即时生成备案服务码
      └─ 主推：ECS 经济型 e 实例 ¥99/年（新老用户同享，续费同价）
      └─ 备选：轻量应用服务器 ¥38（秒杀）/ ¥68（新客价，续费 ¥459）
      ↓
④ 以「个体工商户」主体提交 App 备案（域名栏留空）
```

### 3.5 关于「把个人主体转给王政」的明确结论

> **不能直接转。** 三重封锁：
> 1. **跨省**：ICP 备案不支持跨省变更主体（北京个人 → 河北个体户）。
> 2. **北京管局**：「个人备案不可以变更为其他个人或单位备案」—— 同省也不允许直接变更。
> 3. **阿里云系统**：「目前备案系统**不支持直接**将已备案网站/App 更换到其他主体」，官方只给「注销后重做」或「付费迁移」两条路。

#### 4.2.1 🔴 App 名称「关联性」是单位备案的真实雷区

阿里云官方《填写主体信息和网站信息FAQ》原文：

⚠️ 注意这条写的是**「网站名称」**，而 App 备案填的是**「App 名称」**（官方《填写App信息》对 App 名称只要求「此名称在每个 App 主办者下具有唯一性」）。但同一篇 FAQ 的 App 信息确认段落又写：

> 「网站名称：要求三个及三个以上汉字，且**网站名称需与主办单位名称有关联性**。」

**风险评估**：`小小葵番茄钟`（专注工具品牌名）↔ `遵化市云程智服软件技术服务部`（软件服务个体户）——**字面无关联**，但业务方向一致（软件技术服务 + 专注力 App）。

**三个规避手段（按推荐序）**：
1. ✅ **申请商标注册「小小葵番茄钟」** → 官方明文「如有注册商标可尝试填写商标名称」，这是最硬的关联性依据。但需 **7~12 个月**（周期长，作为长期项并行推进）。
2. ✅ **在「备注」栏主动说明关联关系**（零成本、立即可用）——示例：
   > `本 App 由遵化市云程智服软件技术服务部自主开发运营，为面向儿童的时间管理与专注力养成工具，与单位经营范围一致，不涉及校外培训等需前置审批内容。`
3. ⏳ 若被驳回改名字 → 换含主体关联的名称（如「云程智服小小葵」），但**会破坏商店名/软著名/App 显示名的一致性** ⇒ 连锁成本高，**务必靠手段 1+2 提前规避，不要走到这一步**。

> 📌 **阿里云百科口径**：「同一主体下多个网站/App 的名称可以相同」「可使用单位全称或简称」——即"关联性"是**人工审核裁量项**，不是硬正则。备注栏说清楚 = 最高性价比的解法。

> 📌 **关键路径 = max(软著, App备案) → 商店提审**。App 备案（≈2.5 周）通常**早于**软著（自办 30–40 工作日）下证 → 现在启动 App 备案是**净赚 1 个月**。
> 🔴 **更正（11-12 核实官方原文）**：此前写「App 备案**不含**公安联网备案」**是错的**。官方《ICP备案流程 · 步骤五 ICP备案后处理》原文：「**公安联网备案** —— 依据《计算机信息网络国际联网安全保护管理办法》，**网站/App 开通后 30 天内必须完成公安备案**。请登录全国互联网安全管理服务平台提交公安联网备案申请。」→ **App 也要办**，详见 §5.1。

### 5.1 🔴 下证后的 30 天窗口：公安联网备案（App 也要办）

**官方原文**（阿里云《公安联网备案及注销》）：
> 「如您的网站/App已完成工信部ICP备案，则您**必须**办理公安联网备案。」
> 「各网站/App在工信部进行ICP备案成功后……需在**网站/App开通之日起 30 日内**登录全国互联网安全管理服务平台提交公安联网备案申请。」

| 项 | 内容 |
|---|---|
| 入口 | `https://beian.mps.gov.cn`（全国互联网安全管理服务平台） |
| 注册 | **单位选「法人用户」**（个体户也按单位），下载「**公安一网通办**」APP 扫码人脸认证 |
| 主体审核 | 约 1–3 个工作日 |
| 新办网站 | 填域名（**本 App 无域名**⇒ 按平台对无域名 App 的口径填）、ICP 备案号、服务器 IP、接入服务商（**阿里云计算有限公司**）、安全负责人 |
| 审核 | **5–20 个工作日**，由服务器所在地市级公安局网安支队审核；🔴 **保持手机畅通** |
| 挂号 | 拿到公安备案号后 **30 日内**在 App 内显著位置展示备案号 + 图标 + HTML 代码 |
| 🔴 逾期后果 | 官方依据《计算机信息网络国际联网安全保护管理办法》第 23 条：「不履行备案职责的，由公安机关给予**警告或者停机整顿不超过六个月**的处罚」 |
| 常见驳回 | ICP 备案号错误或未生效 / 服务器 IP 或接入服务商名称不准确 / 联系人电话打不通 / 服务类型与实际不符 |

> 💡 **阿里云可代做**：增值服务「**公安联网备案管家**」（代提交 + 专人对接 + 钉群答疑）。
> 📌 **不必现在做**：公安备案以「App 开通日」起算 30 天，商店提审一般不查公安备案号。**先提审商店，备案号下来后再办**。
> ⚠️ 但**别拖过 30 天**——这条有行政处罚，不是"没影响"。

## 7. 风险与未知项（诚实标注）

| # | 风险 | 等级 | 处置 |
|---|---|---|---|
| R1 | 阿里云表单**强制**要求填「App 全部后台服务域名」 | 中 | 触发 §2.3 降级方案（域名过户 + 注销个人网站备案 + 网站+App 一起报）。⚠️ 会导致隐私政策短暂 404 |
| R2 | 域名「京ICP」个人主体与「冀ICP」个体户主体并存，引发专项核查 | 低 | 工信部专项核查比对的是「同一备案主体下」域名持有者与备案主体一致性；两个主体各自内部自洽即合规。上架稳定后评估是否把网站备案整体迁到个体户 |
| R3 | 隐私政策页脚挂个人 ICP 号，商店人工审核问询 | 低 | 备好说明：网站主体与 App 主体不一致的原因；必要时在隐私政策补一句「网站由个人主体运营，App 由个体工商户运营」 |
| R4 | 商店要求 iOS 平台备案号 | 低 | 追加 iOS 平台特征信息（Bundle ID + Apple 证书 SHA-1 + 公钥） |
| R5 | 备案期间服务器到期 → 服务码作废 | 低 | 阿里云提示：审核期间实例到期，该实例下所有服务码作废。确认到期时间 ≥ 审核结束 + 30 天 |
| **R6** | 🔴 **下证后服务器到期不续费 → 备案号被注销** | **中** | 接入关系空挂 → 核查判「接入不准确」→ 取消接入 → 管局注销风险 → App 内备案号失效 → 商店复审/下架风险。**处置：买 3 年（297 元）或到期前续费；绝不手动「取消接入」**（详见 §3.2.4） |
| R6 | 华为等商店对「单机 App」有免备案通道 | — | 🟢 **不建议走免备案**：国内商店口径不一，且 iOS 国区强制要备案号。统一走正式备案最省事 |
