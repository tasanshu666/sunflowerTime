## 0. 结论先行

### 0.1 一句话

**Android 付费在你的主体条件下，能走通的只有「官网自营卖激活码」这一条主线；应用商店的付费能力对个体工商户基本是关着的，商店版只能先做免费获客。**

### 0.2 四条路，选一条主线

| 路径 | 形态 | 商店合规 | 个体户可行 | 收入归属 | 工程量 | 结论 |
|---|---|---|---|---|---|---|
| **A 商店付费下载** | 商店里标价，付费才能下载 | ✅ 合规 | 华为 ✅ / 应用宝 ⚠️ / 小米·OPPO·vivo ❌ | 商店代收，分成 ~30% | 极低（不写代码） | 覆盖面太小，弃 |
| **B 商店内购 IAP** | 免费下载，App 内买断解锁 | ✅ 合规 | 荣耀 ⚠️ / 华为需鸿蒙重做 / 小米需 ICP 证 ❌ | 商店代收，分成 ~30% | 高（每家一套 SDK） | 中期再评估 |
| **C 官网直供 + 激活码** | 官网下载 APK，卖激活码 | ✅ **完全合规**（自营） | ✅ **可以** | **100% 归你** | 中（一个通道 + 发码服务） | ⭐ **主线** |
| **D 全免费** | Android 不收费 | ✅ | ✅ | 0 | 0 | 兜底 |

### 0.3 三句话记住规则边界

1. **谁收钱**：数字商品在商店里卖，钱必须由商店代收；你在 App 里放自己的收款入口 = 违规。
2. **谁审核**：商店审的是「App 里有没有绕开它收钱」，不是「你在官网卖不卖」。
3. **谁有资质**：自营卖自有软件**不需要 ICP 许可证**（省通信管理局明文），所以个体户办不了 ICP 证这件事**不构成障碍**。

## 1. 先厘清三个被混在一起的问题

团队旧手册（`上架执行手册_安卓国内渠道_v1.md` §6）把「个体户能不能收费」「商店让不让站外付」「要不要 ICP 证」搅在一起，容易得出「Android 付费不可行」的错误结论。拆开看：

| 问题 | 答案 | 依据 |
|---|---|---|
| 个体户能开微信/支付宝收款吗？ | ✅ 能 | 微信支付商户号主体类型可选「个体工商户」，交执照 + 经营者身份证 + 对公/经营者本人卡，1–2 工作日审结 |
| 网站卖自己开发的软件，要 ICP 许可证吗？ | ❌ **不需要** | 广东/海南省通管局公告：「企业利用自身网站、APP 并以自营方式直接销售自身或其它企业的商品或服务，无其它单位或个人以自身名义入驻……不属于增值电信业务，无需取得《增值电信业务经营许可证》」 |
| 商店里卖数字商品能跳站外支付吗？ | 🔴 **绝对不能** | 五大门店同口径；华为处罚最重（见 §3.1） |
| 个体户能办 ICP 许可证吗？ | ❌ 不能（法定须「依法设立的公司」+ 注册资本 ≥100 万） | 但这道门槛**与自营卖软件无关**，别被它带偏 |

> 🔴 **关键推论**：只要你**不在商店版 App 内**出现任何支付入口、跳转、二维码、文案引导，你就能同时做「商店免费版」和「官网卖激活码」。这两件事在合规上不冲突——前提是**两个包物理隔离**（见 §5）。

### 1.1 但有一道新出现的高风险，必须单独确认

**教育移动应用备案。** 教育部《教育移动互联网应用程序备案管理办法》判定标准是「以教职工、学生、家长为主要用户，以教育、学习为主要应用场景」。官方口径里明确区分了「通用类工具不算（如网易有道词典），专用类工具算（如有道少儿词典）」。

本品是**面向 6–12 岁儿童的专用专注力工具**，用户就是孩子 + 家长 → **落在「专用类」的可能性不低**。若被认定为教育移动应用，前置条件是：ICP 备案 + **网络安全等级保护定级备案 + 等级测评报告** + 省级教育行政部门备案。等保测评是一笔真金白银（通常数千至数万元）和数周时间。

**处置建议（P0，本周内做）**：
1. 到 `https://app.eduyun.cn/` 用帮助中心的判定问答自查一遍；
2. 商店上架时**类目不要主动选「教育」**，优先「工具 / 生活 / 健康」——但小米/华为对「儿童」标签有单独审核口径，别用「儿童」规避；
3. 若商店审核要求教 APP 备案号，再补办，不要提前自投。

> 这一条与付费无直接关系，但会**卡住整个 Android 上架**，且比付费更早发生。优先级高于本文其余事项。

## 2. 渠道逐家核查（2026-11 现状）

### 2.1 汇总表

| 渠道 | 个体户能否注册开发者 | 付费形态 | 买断支持 | 卡点 | 结论 |
|---|---|---|---|---|---|
| **华为 AppGallery** | ✅ 可作为经营主体认证 | ① 付费下载 ② IAP 非消耗型 | ✅ 两种都支持 | **纯血鸿蒙不兼容 APK**；付费必须走华为支付 | Android APK 仅覆盖鸿蒙 4.x 及以下存量机；新机必须做鸿蒙版 |
| **荣耀 App Market** | ⚠️ 待实测 | IAP（非消耗型） | ✅ 支持 | 需开通商户服务；主体资质待验 | **最像能跑通的买断 IAP**，且支持无服务端 |
| **小米** | 🔴 报道称已停个体户/个人注册，仅企业 | IAP + 应用联运 | ✅ 支持 | 联运需软著 + ICP 证（或备案）；需商务白名单，非自助 | 短期不可得 |
| **OPPO** | 🔴 个人/个体户入口走企业通道 | 联运（IAP） | ⚠️ | 联运以游戏为主，需版号 | 短期不可得 |
| **vivo** | 🔴 同上 | 联运 SDK | ⚠️ | SDK 名为「游戏联运 SDK」 | 短期不可得 |
| **应用宝（腾讯）** | ⚠️ 个人免费/企业 300 元；个体户待实测 | 付费下载（有官方付费声明） | ✅ | 付费应用入口近年收缩，需商务确认 | 备选，不作主路径 |
| **Google Play** | ✅（需 $25 + 企业账号 D-U-N-S） | 付费下载 + IAP | ✅ | 国内用户访问受限 | 仅出海有意义 |

### 2.2 华为：两条完全不同的路，别混

**路 1：Android APK + 付费下载（贴合买断，但生命周期在收尾）**

- 发布时「付费情况」选「付费」即可；用户首次下载付费，**绑定华为账号**，换机/重装/更新不再收费。
- 审核指南 6.2 原文：「应用如是付费下载应用，**必须选择华为支付服务**」。
- 需开通商户服务 + 签署《华为商户服务协议》；个体工商户可作为经营主体开通（官方论坛答复：执照彩色扫描件 + 统一社会信用代码逐字一致 + 营业期限 > 当前 +90 天）。
- 可选接 `AppGallery DRM Service SDK` 校验购买；**不接也能上，但包会被传播**（官方文档明说）。
- 🔴 **致命限制**：HarmonyOS 5/6/7 已移除 AOSP，不装 APK；且在安卓侧买的付费 App **升级到鸿蒙后无法使用、不支持继承**。存量鸿蒙 4.x 设备还能装，新增用户基本为零。

**路 2：鸿蒙 HAP + IAP Kit 非消耗型（新机的唯一路）**

- 包格式为 `.app`/HAP，需 DevEco Studio + Flutter-OH 分支重做客户端。
- IAP Kit 支持非消耗型（永久买断）；**无服务端也可跑**（客户端拿购买数据 + 签名本地验签，官方明确「对于没有服务端的应用，以上流程同样适用」）。
- 商品价格用华为预设档位，不能任意填。
- 工程量：不是「适配」，是**第二个客户端**（SQLCipher / just_audio / 内购全线要过鸿蒙；Flutter-OH 生态 262 库已适配，需逐个核）。

**华为红线（必须刻在墙上）**
《华为应用市场联运服务协议》附件 B 处罚条款：
- 「非华为官方支付渠道违规」→ 第 1 次下架 30 天，**第 2 次永久下架 + 50 万元 × 违规次数**（或当月应结算款 × 次数，取高）；
- 「诱导非官方渠道下载/登录」→ 含「外链跳转到非华为或合同约定以外的分发平台或网站」，第 1 次下架 3 天，第 3 次永久下架。

⇒ **华为版里连一句「去官网购买」都不能有。**

### 2.3 荣耀：当前最值得试的一家

- 有独立 IAP Kit，商品类型明确包含**非消耗型（一次性购买、永久拥有）**。
- 开通极简：管理中心 → 生态服务 → 应用服务 → 应用内支付服务 → **设置公钥即开通支付权限**。
- **支持「单机流程（没有服务端支持）」**：客户端拿购买数据 + 签名，本地验签即可，适合本项目「无后端」红线。
- 需开通商户服务（收款信息 + 税务信息 + 企业联系人；大陆主体填境内银行账户）。
- ⚠️ 未查到个体工商户明文口径 → **必须实测注册页**。

### 2.4 小米 / OPPO / vivo / 应用宝：为什么现阶段别指望

- **小米**：官方文档原文「Developers who access the Xiaomi IAP service **must be enterprise developers**」；国内联运接入指引要求「联运应用必须有**软著及 ICP 证**」。个体户办不了 ICP 证 → 若严格核验即死。另有报道称小米已停止个体工商户认证（**待实测确认**）。
- **OPPO / vivo**：IAP 主体是「联运」，vivo 的 SDK 直接叫「游戏联运 SDK」，面向游戏（需版号）；工具类内购需商务单独谈。
- **应用宝**：确有「付费应用下载」服务声明（付费应用绑定账号、最多 5 台设备、费用为软件许可费、不退），但入口在商务体系内，近年收缩，需确认是否还对普通开发者开放。

## 3. 推荐方案：双包隔离 + 三阶段

### 3.1 核心设计：两个包，物理隔离

| | **商店包（store）** | **直供包（direct）** |
|---|---|---|
| 分发 | 华为/荣耀/小米/OPPO/vivo/应用宝 | `sunfocused.cn` 官网 |
| 付费入口 | 无（或仅本店 IAP） | 「输入激活码」 |
| 支付相关代码 | 不初始化任何支付 | 仅 Ed25519 验签，**无网络支付** |
| BILLING 权限 | 移除 | 移除 |
| 隐私政策 | 无支付 SDK 披露 | 无支付 SDK 披露 |
| 审核风险 | 零（包里没有任何站外痕迹） | 不经商店审核 |

> 这不是「风味包」这么简单——**是合规隔离**。华为那条 50 万违约金的条款，防的就是「同一份包在不同渠道里悄悄换支付通道」。物理分包是唯一干净的做法。

### 3.2 阶段划分

**阶段 0 · 资质与口径确认（本周，约 3–5 天，0 工程）**

1. APP 备案跑完（进行中）。
2. 网站 ICP 备案过户到个体户主体（手册 §3.2 已规划；**微信支付商户号绑网站时主体必须一致**，不过户会卡住）。
3. 开通微信支付商户号：主体「个体工商户」，类目选 **软件/建站/技术开发 → 软件销售**（备软著）。
4. 对属地通管局提一次书面咨询：「自营网站销售自有软件授权，是否属于增值电信业务？」（拿书面答复，存档）。
5. 实测 3 家注册页（每家 10 分钟）：荣耀、小米、应用宝，只看到不到位「个体工商户营业执照」这一栏。
6. 教育移动应用归属自查（§1.1）。

**阶段 1 · 官网直供 MVP（2 周）**

- 官网加三块：下载页、购买页（微信扫码）、激活说明页。
- 发货：**先人工发码跑前 20–50 单**（0 开发，验证真实付费意愿），再上自动发码。
- App 侧：加「输入激活码」入口（仅 direct 包），Ed25519 离线验签，写入既有 `Entitlement`。
- 目标：跑通「付钱 → 拿码 → 解锁」闭环，拿到第一批真实数据（转化率、退款率、客服问题）。

**阶段 2 · 商店免费版（2–3 周，前提是主体能过注册）**

- 上架 store 包：**不含任何付费入口**，用既有 `entitlement_matrix` 把付费能力放开到免费（或保留轻量限制，靠多孩子档案/深度报告做「未来买断的钩子」，但不做任何购买引导）。
- 目的：品牌背书 + 自然流量 + 安卓端口碑，不谈钱。
- 荣耀若实测通过 → 单独出一个 `honor` 包接 IAP（阶段 3）。

**阶段 3 · 商店付费（条件触发，不排期）**

触发条件（满足任一）：
- 主体升级为有限责任公司 → 打开小米/OPPO/vivo/应用宝 + 可办 ICP 证 + 可谈联运；
- 官网直供月销稳定（证明付费意愿）→ 值得为华为鸿蒙重做一个客户端；
- 荣耀实测通过 → 先做荣耀 IAP（唯一低门槛的商店买断）。

## 5. 激活码技术方案

### 5.1 设计原则

- **离线可用**：不依赖网络，家长断网也能激活（与「离线优先」红线一致）。
- **私钥绝不进 App**：签发在服务端，App 只内置公钥。
- **可撤销**：出问题能停发，但已发出的码无法远程作废（离线代价，接受）。
- **盗版接受度**：买断 + 单机离线必然可被共享/破解。行业默认接受（参考 AnNest、Orange Cloud 做法）。缓解靠：R8 + Dart 混淆（已有）、验签逻辑分散、公钥不明文。

### 5.2 码格式

```
SF1-7K2P-9XQM-4TAV-C3H8
 │   └────────┬────────┘
 │            └ Base32（Crockford，去掉 I/L/O/U 防手误）
 └ 版本位
```

载荷（签名前）：`{"v":1,"pid":"lifetime","sn":12345,"iat":1764000000}`

- `pid`：商品 ID，与 `kIapProductIdLifetime` 同源，**防止换商品复用**；
- `sn`：序列号，本地记录已用（防同机重复输入）；
- `iat`：签发时间，便于追溯批次。

签名：Ed25519（`cryptography` 包，纯 Dart，iOS/Android 通用）。公钥内置 App，私钥只在那台阿里云 ECS 上。

### 5.3 设备与换机

- **第一阶段不做设备绑定**（离线无法强约束，做了也是心理安慰）。
- 文案上承诺「同一激活码可在家庭 3 台设备使用」——靠信任，符合亲子场景（爸爸手机、妈妈手机、平板）。
- **换机**：用户需自行保存激活码；购买时自动邮件发一份（这也是为什么购买页必须收邮箱）。
- 第二阶段（可选）：加一个极简服务端，记录码 → 激活次数，支持自助解绑。

### 5.4 发货链路

```
用户 → 官网购买页（微信扫码 / Native 支付）
     → 微信支付回调（云服务器，验签）
     → 签发激活码（Ed25519）→ 落库 + 页面展示 + 邮件发送
     → 用户在 App 输入 → 本地验签 → 写 Entitlement → 立即生效
```

- **用 Native 扫码支付，不要申请「APP 支付」**。理由：APP 支付申请要求提供应用商店下载链接，官网分发的 APK 大概率过不了；而 Native 支付只要求已备案网站 + 商户号。
- 手机端体验：购买页放二维码，微信内可直接长按识别；非微信浏览器引导「保存图片 → 微信扫一扫」。
- 兜底：支付成功但没收到码 → 后台按订单号补发，页面提供「重新获取」。

## 8. 成本与收益测算

按 iOS 首发价 **$14.99**（口径裁定表记录；中国区档位约 ¥98，以 ASC 实际为准）：

| 渠道 | 到手/单 | 1000 单差额 |
|---|---|---|
| App Store / 国内商店（分成 30%） | ≈ ¥68.6 | — |
| 官网直供（微信 0.6%） | ≈ ¥97.4 | **+¥28.8/单 → 1000 单多 ¥2.88 万** |

固定成本（增量）：微信支付商户号 0 元；云服务器已有；开发者账号 华为/荣耀 0 元、应用宝企业 300 元；软著已有（待公章）。

**结论**：官网直供不只是「合规更容易」，单位经济也明显更好。唯一代价是**没有商店的自然流量**——所以阶段 2 商店免费版的意义是「品牌 + 获客」，不是「卖钱」。

## 9. 待拍板（玄参）

1. **主线确认**：是否接受「官网直供为付费主线、商店只上免费版」？（推荐 ✅）
2. **华为取舍**：是否愿意为一个「纯血鸿蒙客户端」投入（粗估 3–6 周 + 支付/存储/音频全链路适配）？不做则华为新机永久缺席。
3. **免费版策略**：商店版是完全放开（体验最好、零收入），还是保留轻量限制（多孩子档案/深度报告），为将来买断留钩子？
4. **激活设备数**：承诺 3 台（推荐）还是不限？
5. **定价一致性**：官网价与 iOS 中国区价是否对齐？官网略低（省下的 30% 让一部分给用户）还是同价（保护品牌）？
6. **主体升级**：是否启动「个体户 → 有限责任公司」评估（这是打开小米/OPPO/vivo/应用宝和 ICP 证的唯一钥匙，但有记账成本与有限责任的合规义务）。
