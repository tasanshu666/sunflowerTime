## 4. 进度怎么算（这是最需要讲清的一块）

**目标是家长定的，不是系统定的** —— 你说过「这个愿望要多久才能完成，跟专注的关系不大，需要家长自己去设定目标」。所以：

**两种口径**（家长二选一）：
- **口径 0 · 按专注时长**：目标是「累计专注 N 分钟」（默认 30，区间 10~600）
- **口径 1 · 按完成任务数**：目标是「完成 N 个任务」（默认 3，区间 1~5；一个愿望最多挂 5 条任务，所以 N 永远可达成）

**四条护栏**（防孩子「越努力越倒退」）：
1. **分母只写一次** —— 家长增删任务**不改变目标值** ⇒ 进度条不跳动
2. **已完成量永不回退** —— 删任务不把已攒的进度退回去
3. **下调被钳制** —— 家长把目标调小到低于已完成量 ⇒ 当场 100% 成真（正反馈，不是惩罚）
4. **上调有双重护栏 + 二次确认** —— 单次上调 ≤ 原目标 ×50%，且 ≤ 已完成量 ×3

**两种任务要不要家长确认？**
- **专注型**（做口算、做作业）⇒ **自动完成**（做完就计入进度）
- **行为型**（帮妈妈捶背、练钢琴）⇒ **要家长确认**（否则孩子自己点一下就能刷满进度，家长背书就没了）

**愿望任务只能设「一次性」或「每天」** —— 家长在编辑器里选了归属愿望后，重复规则只剩这两档（选「每周」会变灰并说明原因：愿望进度按专注时长/任务个数算，不按星期几）。**孩子自己的普通成长任务不受影响，「每周」照常可选。**

**孩子的「我做到了」** —— 愿望也可以孩子自己实现（自己存够钱、自己考试达标…）。点了就进达成池，**并且同样盖里程碑章**（🔴 你 2026-11-17 拍板：「孩子自己达成的愿望，也需要盖章，这是愿望达成的标志，必须盖章」）。
🔴 **防刷的那道护栏换了个位置**：不再靠「不盖章」拦，而是靠「**章不能白盖**」—— 具体形式有两条候选（① **印章分层**：孩子的章照盖，但池顶那份大荣誉仍只数家长确认过的达成；② **家长可撤销**：孩子点了立刻盖章，但家长在今日页看得见、可以一键退回），**最终以 PRD v0.7.0 的定稿为准**（这一条正在落文档）。
⇒ **孩子自己做到的被承认，但章要盖得「有人兜底」。**

### 6.4 🆕「历史今日」回顾卡片（Q35-②）—— 你提的这个想法，我的判定是：✅ **值得做，而且是整个功能里最贴立意的一块**

你说「**还可以用来回忆**」——「历史今日」正是把这句话**从「翻收藏箱找」变成「它主动来找我」**：孩子某天打开许愿树，树上忽然冒出一张卡说「**去年今天，你许了『去海洋馆看鲸鱼』，后来它实现了**」。**这就是「成长足迹」最直接的呈现方式。**

**它长这样**（许愿树页**最上方**，树上段之上）：
```
┌─────────────────────────────────────────────┐
│  🗓  去年今天，你许了「去海洋馆看鲸鱼」         │
│      ✅ 后来它实现了 —— 2025-03-08 成真         │
│                    [ 看看它 ]   [ 收起 ]      │
└─────────────────────────────────────────────┘
```

**四种结果态**（按被回顾愿望的**当前**位置，**穷举 4 种、不留兜底**）：

| 态 | 判据 | 文案 |
|---|---|---|
| 已实现 | `status == fulfilled` | 「**后来它实现了**」+ 成真日期 |
| 还在树上 | `releasedAt == null && status != fulfilled` | 「**它还在树上等你**」🔴 不用「你还没做到」这类措辞 |
| 进了收藏箱 | `releasedAt != null` | 「**它被收进了愿望收藏箱**」 |
| 换掉了 | `status == abandoned` | 「**你后来换成了别的愿望**」🔴 中性措辞，不评价 |

**七条护栏**（🔴 已写进产品与架构文档）：
① **只在打开许愿树页时判定**，别处不触发（无联网无推送，做不了全局提醒）；🔴【v0.2.0 口径同步 · PRD §4 #12：技术口径**保留**；补充「**孩子授权标记 `sharedToParent` = 家长可见性的唯一开关**」—— 点亮后家长端可见、未点亮家长端无此条；仍无联网无系统推送。】 🔴【v0.3.0 作废并回退：删应用内授权开关，家长端恢复全量可见（不发推送、家长自行处理）。见 PRD v0.3 §1】
