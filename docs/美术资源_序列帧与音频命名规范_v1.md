### §4.4 响度分层定稿（C35，2026-10-07）—— 新素材与重编码的强制规格

**起因（bug F88）**：全库音频响度失控、跨度达 **19 dB**，实测（ffmpeg EBU R128，归一化前）：

| 素材 | LUFS | mean | peak |
|---|---|---|---|
| `shovel.mp3`（铲除） | **−14.8** | −25.3 | −0.3 |
| `cultivate.mp3`（种植） | −16.8 | −24.7 | −6.4 |
| `care_pest.mp3`（除虫） | −18.8 | −28.9 | −10.2 |
| `care_weed.mp3`（除草） | −21.7 | −31.0 | −3.3 |
| `focus_loop.mp3`（专注 BGM） | −25.5 | −28.6 | −14.7 |
| `care_fertilize.mp3` | −31.0 | −36.0 | −11.1 |
| `care_water.mp3` | −32.1 | −38.8 | −11.5 |
| `grow_*.mp3` ×3 | −35 ~ −40 | 约 −42 | — |
| **`background.mp3`（花园氛围音）** | **−38.6** | **−44.8** | **−24.1** |

→ **花园氛围音比铲除音效低 23.8 dB**（峰值差 peak −0.3 −(−24.1)；综合响度差 LUFS −14.8 −(−38.6) 恰为同值 23.8）→ SFX 一响就把背景音完全盖死 → **听成「打断」**；而除草/除虫比铲除轻 3.6~7 dB → 盖不彻底 → **听成「不打断」**。这正是玄参两次听感差异的真正来源（**不是**播放逻辑问题）。

**定稿规格**：

| 类别 | 目标响度 | 说明 |
|---|---|---|
| SFX（`assets/audio/sfx/*.mp3`） | **−20 LUFS** | 比BGM 高 6 dB，确保音效能被听见 |
| BGM（`assets/audio/bgm/*.mp3`） | **−26 LUFS** | 垫底不抢戏 |
| 花园氛围音 `background.mp3` | **−31.3 LUFS** | 应玄参「背景音有点大」反馈，在 −26 基础上**再降 4.7 dB**；比 SFX 低 11 dB（垫底但可闻） |

**执行方式（硬规矩）**：
- **纯增益归一化**（ffmpeg `-af volume=XdB`），**禁止动态压缩**（会改变波形与听感动态）。
- **峰值上限 ≤ −1.0 dBFS**：达不到目标响度的文件**按峰值封顶即止**，不强推（否则削波失真）。本轮有 4 个文件因此未达目标值，属正常。
- **时长分毫未变**：响度调整与「≥3s 红线」解耦——帧/动画时长一律由 `prd_params.dart` 常量驱动（如 `kCareWaterDurationMs`），**不因重编码而改动常量**。
- 输出规格统一 **44.1 kHz / 立体声 / 192 kbps mp3**。
- 改动前**必须全量备份原件**（本轮备份在 `/tmp/audio_backup_20261007/`，20 个文件）。
- 归一化脚本：`/tmp/norm_audio.py`（`--apply` 开关，执行前后打印实测值；规则 = BGM → −26 / SFX → −20 /峰值封顶 −1.0）。

⚠️ **配套的 duck 深度**：因氛围音已提亮到 −26 LUFS，`kSfxDuckAmbientVolume` 必须同步由 **0.35 → 0.80**（−9.1 dB → −1.9 dB）；仍按 0.35 压等于把背景音**重新按回听不见** → 仍被听成「打断」。**响度与 duck 深度是两个 coupled 的量，改其一必须复查另一。**
