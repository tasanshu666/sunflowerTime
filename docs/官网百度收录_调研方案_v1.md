## 一句话结论

**官网搜不到的根因不是那段 JS 爬虫重定向（它明确放行 `baiduspider`，对百度抓取有利，不要删），而是「从未在百度搜索资源平台提交 + 无外链孤岛新站 + 时间未到」三件事叠加；EdgeOne 海外节点只是次要摩擦项，而且域名已备案、可低成本切到含大陆节点。**
P0 只有三件事：① 站点验证并补全备案/主体/领域信息 ② 普通收录提交（手动 + sitemap）③ 抓取诊断自检。全程基本不需要改官网代码（除非选 HTML 标签验证，需加 1 行 meta）。

## 根因分层诊断

### 1. 技术层：基本健康，唯一的"嫌疑"其实是好事

| 项 | 当前状态 | 对百度的影响 | 证据/来源 |
|---|---|---|---|
| 站点可访问 | 实测 `HTTP 200`、响应 0.7～1s、`Server: edgeone makers` + COS 后端 | ✅ 加分（连通性无问题） | 本地 curl 实测 2026-11-28 |
| `robots.txt` | `User-agent: * / Allow: / / Disallow: /tools/`，含 `Sitemap:` 声明，线上 200 | ✅ 加分（未封 baiduspider） | 实测 + [百度官方：Robots 设置](https://ziyuan.baidu.com/college/articleinfo?id=3541)（查阅 2026-11-28） |
| `sitemap.xml` | 4 个 URL 的普通 `urlset`，非"索引型 sitemap"，线上 200 | ✅ 加分（符合百度要求，百度明确"索引型 sitemap 不予处理"） | 实测 + [资源平台工具解读](https://ziyuan.baidu.com/college/articleinfo?id=3077)（2026-11-28） |
| `canonical` | 首页指向 `https://sunfocused.cn/`，英文站指向 `/en/` | ✅ 加分。百度官方点名 `domain/index.html` 属"首选域不唯一"问题，当前 canonical 已规避 | [搜索优化 2021](https://ziyuan.baidu.com/college/articleinfo?id=3249)（2026-11-28） |
| **JS 语言重定向** | `<head>` 内脚本正则含 `baiduspider`（`/i` 大小写不敏感，覆盖 `Baiduspider/2.0`），命中即 `return`；普通用户 `/index.html` 才按浏览器语言跳 `/` 或 `/en/` | ✅ **有利/中性，不是搜不到的原因**。实测用 Baiduspider UA 请求 `/` 返回完整 92470 字节 HTML、无跳转；百度抓 `/` 能拿到中文正文，不会因 JS 跳走丢权重 | 实测 + 源码 `index.html:15-46`（2026-11-28） |
| `hreflang` 中英互指 | head + sitemap 两处声明，内容一致 | ⚪ 中性。百度官方**无明确支持声明**（第三方说法互相矛盾），不减分，但别指望靠它解决收录 | [重复页面判定 Q&A](https://ziyuan.baidu.com/college/articleinfo?id=3195)（2026-11-28）；官方未检索到 hreflang 支持条款 |
| 海外节点 | EdgeOne Pages，响应头见 `x-cos-*`、`EO-Cache-Status`，加速区域疑为"全球可用区（不含中国大陆）" | ⚠️ 次要摩擦项。百度官方：抓取异常会影响抓取、索引、权重；跨境链路是否慢需靠"抓取诊断"实测，不能凭本地 curl 下结论 | [百度搜索工作原理](https://ziyuan.baidu.com/college/articleinfo?id=3541) + [EdgeOne Pages 域名管理](https://edgeone.ai/zh/document/160427672892563456)（2026-11-28） |

**关键澄清（针对团队线索）**：那段 JS 对百度是**保护性**的——爬虫 UA 命中就直接 `return`，不做任何跳转。百度抓 `sunfocused.cn/` 时看到的就是完整中文首页；只有真人才会跳。所谓"JS 重定向丢权重"在此不成立。**唯一要守住的底线：以后改 UA 正则必须保留 `baiduspider` 放行**，否则 sells 变坏事。

### 2. 提交层：头号根因——百度根本不知道这个站存在

- 百度 Spider 的机制是"从种子 URL 出发，沿页面超链接不断发现新 URL"（[官方工作原理](https://ziyuan.baidu.com/college/articleinfo?id=3541)，2026-11-28）。纯新站、无外链 = 官方所说的**"孤岛页面"**。
- 官方明确："网页没有被搜索引擎发现，因为网页没有放置外部链接，本身是个孤岛页面……针对网站始终没有被百度抓取的情况，建议使用普通收录工具进行提交"（[平台工具使用手册](https://ziyuan.baidu.com/college/articleinfo?id=2004)，2026-11-28）。
- 官方还把"在资源平台绑定站点、填写备案号、关联主体、选择站点类型与领域"列为**新站收录很有必要的一步**（[搜索优化 2021](https://ziyuan.baidu.com/college/articleinfo?id=3249)，2026-11-28）。玄参 `.cn` 已备案却未用到这个信号。
- **现状**：站点未在百度搜索资源平台验证/提交 → 计时器几乎没开始走。这是搜不到的最直接原因。

### 3. 权重层：新站天然弱势，通用词短期无解

- 官方排序维度：**相关性、权威性、时效性、内容质量**；"权威性：用户喜欢有一定权威性网站提供的内容"（[工作原理](https://ziyuan.baidu.com/college/articleinfo?id=3541)，2026-11-28）。新域名无外链、无历史，权威性信号为零。
- 索引库分层级：优质库/普通库/低级库，低级库展现机会小；官方点名"**主体内容空短的网页**""重复内容的网页"可能根本不被索引。玄参站仅 4 个 URL、其中 2 个是隐私政策，首页为介绍型 landing，属高风险。
- 官方对模板相同是否判重复："页面内容不一样且是优质的内容，则不会被判为重复页面"（[Q&A](https://ziyuan.baidu.com/college/articleinfo?id=3195)，2026-11-28）→ 中英两套是真实不同语言内容，重复风险低。

### 4. 时间层：官方没有"固定沙盒天数"，别信传言

- 官方页面级口径："页面从产生到收录需要一定周期，时间从**几分钟到几天**不等，取决于网页的搜索价值和重要性"（[id=2004](https://ziyuan.baidu.com/college/articleinfo?id=2004)，2026-11-28）。
- 官方站点级口径："**新站收录存在一定的时间周期**，搜索引擎通常需要花费一定时间来评估新站的质量"（[id=3249](https://ziyuan.baidu.com/college/articleinfo?id=3249)，2026-11-28）。
- **百度从未公布固定的"沙盒期"时长**。任何"1 个月/3 个月"都是行业经验值，不是官方规则。
- 现实预期（经验值，非官方承诺）：提交后 **1～4 周**首页被 `site:` 查到属常见区间；稳定排名需 **1～3 个月**持续内容+外链积累。站点 2026-10 上线，但因未提交，真正计时从提交那天算。

## 解决方案（按优先级）

### P0 — 立刻做（合计约 1～2 小时，基本不改代码）

#### P0-1 注册百度搜索资源平台并完成站点验证、补全备案/主体/领域
- **做什么**：拿到站长权限，把"已备案"这个信号用起来。
- **具体步骤**（照着点）：
  1. 打开 `https://ziyuan.baidu.com`，用百度账号登录 → 用户中心 → 联系方式模块补全开发者信息。
  2. 用户中心 → 站点管理 → 添加网站 → 输入 **`https://sunfocused.cn`**（HTTPS 站必须带协议头，官方强调）。
  3. 站点类型分类；**站点领域必填 1～3 项**（官方："站点领域信息必须填写，需填写 1-3 项"）。
  4. 选验证方式（二选一）：
     - **HTML 标签验证（推荐）**：复制平台给的 `<meta name="baidu-site-verification" ...>`，贴进 `index.html` 的 `<head>`，重新部署。**需改 1 行代码**。
     - **文件验证**：下载验证文件 → 放到站点根目录 → 提交到工程仓库并重新部署。**需加 1 个文件**。
     - ⚠️ 官方提醒"首页有跳转可能验证失败"。当前 JS 对 Baiduspider 放行，理论上能过；若验证失败，临时用 `?lang=zh` 访问或换另一种方式（[站点验证图文详解](https://ziyuan.baidu.com/college/videoinfo?id=1485)，2026-11-28）。
  5. 验证通过后，站点管理里**填写备案号**、**关联站点主体**（个人主体需先在百家号注册同名主体；关联后 7 天内不可解除，谨慎填）（[站点关联主体](https://ziyuan.baidu.com/college/videoinfo?id=2897)，2026-11-28）。
- **预期效果**：解锁普通收录、抓取诊断、索引量等全部工具；备案+主体成为信任信号。
- **时间成本**：30～60 分钟。
- **是否改代码**：可能（HTML 标签验证加 1 行 meta / 文件验证加 1 个文件）。

#### P0-2 普通收录提交（先手动 + sitemap，最快见效）
- **做什么**：主动告诉百度"这些页面存在"，而不是等蜘蛛自己发现。
- **具体步骤**：
  1. 资源提交 → 普通收录 → **手动提交**：逐条贴入 4 个 URL：
     - `https://sunfocused.cn/`
     - `https://sunfocused.cn/en/`
     - `https://sunfocused.cn/privacy.html`
     - `https://sunfocused.cn/privacy-en.html`
  2. 同一页面 → **sitemap 提交**：填入 `https://sunfocused.cn/sitemap.xml` 提交（当前是普通 urlset、非索引型，合规）。
  3. （可选，效果最好）**API 提交**：普通收录 → API 提交 → 复制 token → 本地执行：
     ```bash
     printf '%s\n' \
       'https://sunfocused.cn/' \
       'https://sunfocused.cn/en/' \
       'https://sunfocused.cn/privacy.html' \
       'https://sunfocused.cn/privacy-en.html' \
       > urls.txt
     curl -H 'Content-Type:text/plain' --data-binary @urls.txt \
       "http://data.zz.baidu.com/urls?site=sunfocused.cn&token=你的token"
     ```
     （官方 curl 示例见 [平台工具使用手册](https://ziyuan.baidu.com/wiki/93)，2026-11-28；API 为"最为快速"的方式，共享配额 10w/天）
  4. 注意官方规则：**如链接存在跳转关系，直接提交跳转后的链接**（[id=3077](https://ziyuan.baidu.com/college/articleinfo?id=3077)，2026-11-28）→ 提交 `/` 而非 `/index.html`。
- **预期效果**：把"发现链接"从数周缩短到数天。sitemap 会被周期性抓取检查，收录速度慢于 API；手动最慢但零门槛。
- **时间成本**：手动 + sitemap 约 10～20 分钟。
- **是否改代码**：否（除非做 API 自动化，见 P2-7）。

#### P0-3 抓取诊断自检（确认技术层真的没问题）
- **做什么**：站在百度蜘蛛视角看一眼，避免"瞎改代码"。
- **具体步骤**：
  1. 打开 `https://ziyuan.baidu.com/crawltools/index`（官方"抓取诊断"工具，链接见 [id=2004](https://ziyuan.baidu.com/college/articleinfo?id=2004)，2026-11-28）。
  2. 输入 `https://sunfocused.cn/` → 发起诊断 → 查看百度蜘蛛实际拿到的 HTML、状态码、跳转链路。
  3. **合格判定**：`200` + 中文正文 + **无跳转到 `/en/`**。若看到跳转到英文页或内容为空，才需要回头改 JS 逻辑（按现状判断几乎不会）。
  4. 顺手检查：**抓取异常**（`https://ziyuan.baidu.com/crawl/index`）看有无失败；**Robots 工具**（`https://ziyuan.baidu.com/robots/index`）确认 baiduspider 未被封；**索引量**（`https://ziyuan.baidu.com/indexs/index`）记基线。
- **预期效果**：一次确认"技术层清白"，把精力全放在提交和等待上。
- **时间成本**：15 分钟。
- **是否改代码**：否。

### P1 — 1～4 周内做（增强信号，提速数天到数周）

#### P1-4 EdgeOne 加速区域切到"含中国大陆"节点
- **做什么**：消除跨境抓取这个次要摩擦项。
- **依据**：EdgeOne Pages 官方文档明确三档加速区域——"中国大陆可用区"与"全球可用区"**需工信部备案**；"全球可用区（不含中国大陆）"无需备案，且该档位下大陆网络访问项目域名返回 401（[域名管理](https://edgeone.ai/zh/document/160427672892563456)、[概览](https://edgeone.ai/document/175201428435140608)，2026-11-28）。玄参 `.cn` **已完成 ICP 备案，具备切换资格**。
- **具体步骤**：EdgeOne 控制台 → Pages 项目 → 项目设置/域名管理 → 加速区域 → 选 **"全球可用区"**（含大陆，兼顾海外用户，折中推荐）或"中国大陆可用区"（大陆最快、海外可能变慢）→ 保存，DNS 生效最长 48h。
- **预期效果**：降低 Baiduspider 跨境超时/失败概率；官方明确抓取异常会负面影响抓取、索引、权重（[工作原理](https://ziyuan.baidu.com/college/articleinfo?id=3541)，2026-11-28）。
- **时间成本**：10 分钟 + 等待生效。
- **是否改代码**：否。
- **取舍**：若当前已是"含大陆"档位，此步跳过。

#### P1-5 补外链与入口，打破孤岛
- **依据**：官方建议"适当增加新网站首页的高质量友情链接，提高百度蜘蛛抓取的几率""新增页面在首页有适当的展现入口"（[搜索优化 2021](https://ziyuan.baidu.com/college/articleinfo?id=3249)，2026-11-28）。
- **具体步骤**：App 内"关于/官网"跳转入口、GitHub README 官网链接、社交账号简介、应用商店开发者主页、个人技术博客/社区签名。**只做真实相关的高质量链接，不买链**。
- **预期效果**：提高被发现概率 + 权威性信号。
- **时间成本**：半天（App 入口需排期发版）。
- **是否改代码**：可能（App 内加链接需发版）。

#### P1-6 内容补强（规避"主体内容空短"）
- **依据**：官方点名"主体内容空短的网页"可能不被索引；优质库标准=领域垂直、质量高、原创、体验好（[工作原理](https://ziyuan.baidu.com/college/articleinfo?id=3541)，2026-11-28）。
- **具体步骤**：在中文站新增 1～3 篇原创图文（如"6–12 岁孩子专注力习惯养成指南""番茄钟怎么用才有效"），从首页导航链过去；同步更新 `sitemap.xml` 并重新提交。**必须原创/深度本地化，不要机翻或复制**。
- **预期效果**：增加可索引页面 + 覆盖长尾词，提升进优质索引库概率。
- **时间成本**：1～2 天。
- **是否改代码**：是（加页面 + 更新 sitemap + 重新提交）。

### P2 — 可选/长期

#### P2-7 API 推送自动化
在 `GitHub Actions` 部署成功后自动调用 API 推送（token 存 Secrets）。官方：API 推送"最为快速"、共享配额 10w/天（[工具手册](https://ziyuan.baidu.com/wiki/93)，2026-11-28）。**需改 CI 配置**。适合内容频繁更新后长期维护。

#### P2-8 英文站 `/en/` 的处理（明确结论）
- **要不要提交给百度**：可以随 sitemap 一并提交（P0-2 已含），零成本；但**百度主场景是中文搜索，英文页在百度几乎带不来流量**，不值得为百度单独优化英文站。
- **会不会判重复**：不会。中英是两种不同语言的真实内容，官方口径是"页面内容不一样且是优质的内容，则不会被判为重复页面"（[Q&A](https://ziyuan.baidu.com/college/articleinfo?id=3195)，2026-11-28）。
- **hreflang 百度认不认**：**官方无明确支持声明**（检索到的第三方说法互相矛盾，有的说"官方未明确支持"、有的说"会参考"）。结论：当前 head + sitemap 两处写法**不减分，保留即可**，但不要指望它解决收录问题；主力语言区分靠 `lang` 属性 + 独立 URL + 真实内容。
- **是否改代码**：否。

## 现实预期与不建议做的事

### 现实预期
| 目标 | 预期 | 性质 |
|---|---|---|
| `site:sunfocused.cn` 能查到首页 | 提交后 **1～4 周** | 经验值（官方仅说页面级"几分钟到几天"、站点级"需要一定周期"，无固定沙盒天数） |
| 搜品牌词"小小葵番茄钟"能找到 | 收录后较易实现（唯一性强） | 经验值 |
| 搜通用词"番茄钟""儿童专注力"有排名 | **短期不可能**，需数月内容+外链积累 | 官方排序含"权威性"维度，新站天然缺失（[工作原理](https://ziyuan.baidu.com/college/articleinfo?id=3541)，2026-11-28） |
| 索引量 > 0 | 最快每天、最迟一周更新一次数据 | 官方口径（[工具解读](https://ziyuan.baidu.com/college/videoinfo?id=3159)，2026-11-28） |

> 特别提醒：通用词搜不到**不等于**官网有问题。新站、无外链、无百度权重，通用词短期没排名是正常的；先把"品牌词能搜到"作为第一阶段目标。

### 不建议做的事（踩坑清单）
- ❌ **买排名、买外链、关键词堆砌、隐藏文本、镜像站**——属官方定义的违规作弊，可能导致整站不收录（[工作原理](https://ziyuan.baidu.com/college/articleinfo?id=3541)，2026-11-28）。
- ❌ **不要删 JS 里的 `baiduspider` 放行逻辑**——删了才会让百度抓到跳转/空内容，得不偿失。

2. **索引量工具**：`https://ziyuan.baidu.com/indexs/index` → 看索引量是否从 0 变正；数据最快每天、最迟一周更新一次。
