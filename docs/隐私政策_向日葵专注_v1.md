- 👨‍👩‍👧 **家长请读**：您孩子在本 App 里产生的所有数据都只存在您自己的手机里，没有账号、没有云端、没有第三方。

## 三、我们收集什么（几乎为零）

**核心事实：本应用没有任何网络上传通道，所有数据仅存储于设备本地加密数据库。**

| 我们 **不** 做的 | 说明 |
|---|---|
| 不收集个人信息 | 不收集姓名、手机号、位置、通讯录、相册、相机、麦克风等任何可识别个人的信息 |
| 不要账号 | 无注册、无登录、无云端账号 |
| 不接第三方 SDK | 无统计、无广告、无推送、无社交分享、无地图等任何第三方 SDK |
| 不做用户追踪 | 无任何埋点上报、无设备指纹、无跨应用追踪 |

| 仅存于本机的本地数据（不上传） | 存储位置 |
|---|---|
| 专注计时记录、植物养成进度 | 本地加密数据库（SQLCipher） |
| 家长 PIN（仅存 **sha256 + salt 哈希**，不可逆、不存明文） | 系统安全区（flutter_secure_storage） |
| 应用设置、奖励模板 | 本地键值存储（shared_preferences） |

## 四、系统权限说明（以 AndroidManifest 为准）

应用实际声明的权限如下，**没有任何网络权限**，因此不存在任何网络传输。

| 权限 | 类型 | 用途 | 是否必须 |
|---|---|---|---|
| `android.permission.ACCESS_NOTIFICATION_POLICY` | 普通权限（安装即授予，无弹窗询问） | 用于专注期间管控通知打扰（勿扰策略），帮助孩子安静专注 | 可选；未启用也不影响核心功能（见下方待确认） |
| 网络权限（INTERNET / ACCESS_NETWORK_STATE 等） | — | **未声明** → 应用无任何联网能力 | — |
| 定位 / 相机 / 麦克风 / 通讯录 / 存储读写等 | — | **未声明** | — |

> ⚠️ **待确认项**：`ACCESS_NOTIFICATION_POLICY` 的实际功能接线需工程侧确认（专注期是否真的启用静音/勿扰）。若该能力未实装，建议评估移除该声明，以进一步简化隐私叙述、降低审核问询。
>
> 说明：AndroidManifest 中的 `<queries>`（PROCESS_TEXT）是**包可见性声明，不是权限**，不影响用户隐私，无需在权限列表披露。

## 五、数据存储与安全

- 业务数据采用 **本地加密数据库（SQLCipher）** 存储，密钥随应用安装生成、不离开设备。
- 家长 PIN 以 **sha256 + 随机 salt 哈希** 存于系统安全区（Keystore / Keychain 等价物），**不保存明文、不可反推**。
- 数据 **不上云、不同步、不备份到任何第三方服务**。
- **卸载应用即删除全部本地数据**：加密库与键值存储随应用数据目录一并清除，不留残留。
