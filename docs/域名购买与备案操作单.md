> **日期**：2026-11-12 ｜ **账号**：`sunflower-gts`（个体户认证）

## ✅ 先看结论（3 个问题 3 行答案）

| 你的疑问 | 答案 |
|---|---|
| 是不是就买一个域名就行？ | ✅ **对，就一个**。App 备案表单里「App 全部后台服务域名」填一个即可 |
| 域名需不需要单独备案？ | ❌ **不需要**。它跟着**这一次 App 备案**一起报给管局，拿到的是 App 备案号（`冀ICP备xxx号-xA`） |
| 那域名要做什么手续？ | ✅ **实名认证**（≠ 备案）。不做实名 → 域名状态 `serverHold` → 备案实时核验直接失败 |

## 💰 第 1 步 · 买域名（10 分钟）

**入口**：`sunflower-gts` 账号 → [wanwang.aliyun.com/domain](https://wanwang.aliyun.com/domain)

| 项 | 选什么 |
|---|---|
| 后缀 | 🔴 **`.cn`**（国内主体首选，备案路径最清晰）。备选 `.com` |
| 🔴 **必须避开** | `.io` `.ai` `.app` `.dev` ❌ **不在工信部批复名单，不可备案** |
| 年限 | ✅ **5~8 年**（多年注册 9.1 折，锁价不受涨价影响）<br>❌ **别买 1 年**（到期释放 → 备案接入不实 → 取消接入风险） |
| 价格 | `.cn` 首年 ¥30（**11.10–11.12 闪促单�� ¥14**）｜续费 ¥42/年<br>`.com` 首年 ¥76｜续费 ¥90/年 |
| 名字建议 | 与 App/主体有联想，便于以后做官网：`xxx.cn`（如品牌词、商标词） |

**买完立刻记下**：域名、到期日、订单号。

## 📋 第 2 步 · 建信息模板并做实名认证（15 分钟 + 审核 1~3 天）

**入口**：域名控制台 → [信息模板](https://dc.console.aliyun.com/#/info-stencil/infoStencil) → **创建新信息模板**

### 逐字照抄这 9 个字段

| 字段 | 填写内容 | 🔴 注意 |
|---|---|---|
| 模板类型 | **企业 / 组织** | ❌ 不是「个人」 |
| **域名持有者单位名称** | `遵化市云程智服软件技术服务部（个体工商户）` | 🔴🔴 **「（个体工商户）」5 个字 + 全角括号必须带上！** 系统 OCR 常漏，系统报错说不一致时**手动补全再提交** |
| 证件类型 | **工商营业执照** | ❌ 不是身份证、不是组织机构代码证 |
| 统一社会信用代码 | `92130281MAKRRERD1N` | 🔴 **不填副本号 (1/1)**；注意区分数字 0 与字母 O、1 与 I、8 与 B |
| 所属区域 | 河北省 / 唐山市 / 遵化市 | 与证件注册地址一致 |
| 通讯地址 | 与营业执照一致（港陆花园101栋4门702号） | 超 128 字符可缩写保留省市区+门牌号 |
| 邮编 | 064000 | — |
| 域名联系人 | **玄参本人**（姓名 + 188 + 邮箱） | ✅ 官方明文：**不强制法定代表人**，且**无需联系人信息认证** |
| 电子邮箱 | 玄参常用邮箱 | **必须完成邮箱验证**；❌ 避免 `test@test.club` 这类新顶级域后缀邮箱 |

### 执照上传要求

- 格式：JPG / JPEG / PNG / BMP / HEIC / WebP
- 大小：**55KB ~ 5MB**
- 彩色**原件**扫描件或数码照片（❌ 不接受复印件）
- **四个边角完整入镜**、无遮挡、无涂抹、无反光不模糊
- ❌ 严禁 PS 或手动修改

### 审核时长

- 信息模板：**1 个工作日**（部分 3~5 个工作日）
- 状态变「**模板实名成功**」才继续

## 🔗 第 3 步 · 关联到域名（2 分钟 + 审核 1~3 天）

| 场景 | 操作 |
|---|---|
| **新注册域名**（你的情况） | 订单确认页直接选已成功的模板 → 支付后系统自动提交认证 |
| 已有域名 | 域名列表 → 点域名 → 「域名持有者实名认证」→ **快速认证** → 选模板 |

**查状态**：域名列表 → 目标域名状态变成 **「正常」** = 实名认证完成 ✅

## ⏳ 第 4 步 · 等同步，然后回 App 备案填域名（2~3 天）

🔴 **域名状态变「正常」后，还要再等 2~3 天**，信息才同步到通信管理局系统，此时才能提交备案订单。
> 官方原文：「域名实名认证或过户成功后信息需要至少 **2 天**同步至通信管理局系统，请在域名认证审核通过至少 2 天后提交备案订单」

### 回 `beian.aliyun.com` 填这两处

| 位置 | 填什么 |
|---|---|
| **3A · App 基础信息 → App 全部后台服务域名** | 你的新域名（**不带 www，不带 http**） |
| **3C · 安卓平台 → 具体使用的域名** | 🔴 **从上面已填域名中下拉选**（不能手输） |

### 同一时刻把这两个错一起修掉

| 字段 | 改成 |
|---|---|
| **证书 MD5 指纹** | `4B29624881F8E64E18600E59EC7E6E6F` ← **32 位连续十六进制，去掉冒号**（当前报错就是带冒号导致） |

## 📌 三个必须提前确认的事

1. 🔴 **营业执照签发日期** —— 官方答人原文：「**新办证件需要等待证件颁发 10 天后才能提交备案**」⇒ 若签发日距今不足 10 天，域名就算认证完也得等
2. 🔴 **营业执照经营范围** —— 是否含「软件开发 / 信息技术服务」？不含的话商店提审会卡（网店执照常见只有电商类目）⇒ 需办**经营范围变更**（个体户免费、线上办、承诺 1 个工作日）
3. 🔴 **App 名称关联性** —— 备注栏要写清「本 App 由遵化市云程智服软件技术服务部自主开发运营」
