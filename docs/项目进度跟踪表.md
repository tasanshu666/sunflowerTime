### 美术命名现状（与出图契约的对应关系）

玄参本轮实际采用的是**「基础态用二级、特殊态用一级」**的混合命名，**合法且推荐**（三级回退天然支持）：

```
基础态（成长中）   assets/plants/{speciesId}_{stage}.png            例：species_sunflower_adult.png
特殊态（枯萎/枯死/盛开） assets/plants/{speciesId}_{stage}_{status}.png  例：species_sunflower_adult_wilting.png
```

- `species_sunflower_seed_dead.png` 已存在但**实际不可达**（见美术清单 §3.2：普通植物阶段短，死亡时刻不早于 seed→sprout 推进）→ 留着无害。**普通两物种（向日葵/雏菊）不需要出 `seed_dead`；但精品仙人掌（480h/阶段）需要**（枯萎 3 天 + 死亡 7 天发生在种子期以内）。详见 `docs/美术资源清单_花园植物.md` §3.2。
- **新图入库后必须跑** `tools/normalize_plant_art.py` 归一化到 1200×2000，否则会因透明留白导致「显示过小」。
