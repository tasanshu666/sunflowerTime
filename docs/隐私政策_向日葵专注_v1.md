## 一、写给家长和小朋友的话（双读者说明）

小小葵番茄钟（英文版名 Tiny Sunflower）是一款帮孩子练习「安静专注」的工具型 App：孩子用专注计时赚到「阳光」，在花园里养植物、兑换家长设置的奖励。**它不是一个收集你信息的产品**：我们不会把你的任何数据上传到我们自己的服务器，也不做任何追踪。（App 内购买由应用商店 Apple / Google 结算，详见第四节。）

- 👨‍👩‍👧 **家长请读**：您孩子在本 App 里产生的所有数据都只存在您自己的手机里，没有账号、没有云端，也不会发给我们或任何第三方。购买功能由应用商店（Apple / Google）提供，我们既不接触、也不保存您的支付信息。
- 🌻 **小朋友请读**：这个 App 不会问你的名字、电话、住在哪里，也不会把你的任何信息发给别人，放心用。

## 三、我们收集什么（几乎为零）

**核心事实：本应用没有任何用于上传用户数据的网络通道——所有数据仅存储于设备本地加密数据库。**

| 我们 **不** 做的 | 说明 |
|---|---|
| 不收集个人信息 | 不收集姓名、手机号、位置、通讯录、相册、相机、麦克风等任何可识别个人的信息 |
| 不要账号 | 无注册、无登录、无云端账号 |
| 不接第三方 SDK（唯一例外见右） | 无统计、无广告、无推送、无社交分享、无地图等第三方 SDK；唯一引入的第三方组件是**系统级应用内购买结算库**（iOS StoreKit / Android Google Play Billing），仅用于「永久买断」付款与「恢复购买」，**不用于上传用户数据** |
| 不做用户追踪 | 无任何埋点上报、无设备指纹、无跨应用追踪 |

| 仅存于本机的本地数据（不上传） | 存储位置 |
|---|---|
| 专注计时记录、植物养成进度 | 本地加密数据库（SQLCipher） |
| 家长 PIN（仅存 **sha256 + salt 哈希**，不可逆、不存明文） | 系统安全区（flutter_secure_storage） |
| 应用设置、奖励模板 | 本地键值存储（shared_preferences） |

## 四、系统权限说明（以 AndroidManifest 为准）

下表按 **Android 版** 构建产物中合并后的 `AndroidManifest.xml` 实际声明逐条列出（实测自 `flutter build apk --release`）。

**要点**：`ACCESS_NETWORK_STATE` / `INTERNET` / `com.android.vending.BILLING` 均由依赖库**自动合并引入**，只服务于应用内购买结算；**本应用没有任何用于上传用户数据的网络通道**。

| 权限 | 类型 | 用途 | 是否必须 |
|---|---|---|---|
| `android.permission.ACCESS_NOTIFICATION_POLICY` | 普通权限（安装即授予，无弹窗询问） | 用于专注期间**屏蔽通知打扰（勿扰策略）**，帮助孩子安静专注；实现见 `lib/platform/dnd_controller.dart` 与 `android/app/src/main/kotlin/com/sunflowertime/app/MainActivity.kt` | **已实装**（专注期在用；入口页可开关，默认开启） |
| `android.permission.ACCESS_NETWORK_STATE` | 普通权限（安装即授予） | **非本应用主动申请**：由音频库 `just_audio`（`androidx.media3:media3-exoplayer`）自动合并引入，仅读取网络连接状态。**不涉及任何用户数据传输** | 依赖库附带 |
| `com.android.vending.BILLING` | 普通权限（安装即授予） | 由应用内购买库 `in_app_purchase_android`（Google Play Billing）引入，**仅用于「永久买断」付款与「恢复购买」**，不涉及上传用户数据 | 购买功能必需 |
| `android.permission.INTERNET` | 普通权限（安装即授予） | 由同一结算链路（`com.google.android.datatransport`）自动合并引入，供结算库与 Google Play 通信以完成付款/校验。**不用于上传用户数据** | 购买功能必需 |
| 定位 / 相机 / 麦克风 / 通讯录 / 存储读写等 | — | **未声明** | — |

> **平台差异说明**：上表各项均为 **Android** 侧声明。**iOS 版不声明任何网络类权限**（iOS 无 INTERNET 权限概念），购买与恢复购买由 Apple StoreKit 完成；两平台均**不向开发者或任何第三方服务器上传用户数据**。

> **说明（已实装）**：`ACCESS_NOTIFICATION_POLICY` **已实装并在用**——孩子进入专注时开启系统勿扰、屏蔽通知打扰，退出专注时恢复；入口页可开关，默认开启。实现见 `lib/platform/dnd_controller.dart`（`MethodChannel('sunfocus/dnd')`：`isGranted()` / `requestAccess()` / `setEnabled()`）与 `android/app/src/main/kotlin/com/sunflowertime/app/MainActivity.kt`（`:27` `isNotificationPolicyAccessGranted`；`:47` / `:48` `INTERRUPTION_FILTER_PRIORITY` / `INTERRUPTION_FILTER_ALL`）。该权限仅作用于系统勿扰，**不涉及任何网络传输或用户数据上传**。
>
> 说明：AndroidManifest 中的 `<queries>`（PROCESS_TEXT）是**包可见性声明，不是权限**，不影响用户隐私，无需在权限列表披露。

## 五、购买与退款（一次性买断）

**本 App 采用一次性买断（非消耗型内购，Non-Consumable）**：付费一次即永久解锁，**不是订阅、不会自动续费、没有任何周期性扣费**。

| 事项 | 说明 |
|---|---|
| 支付处理方 | **Apple App Store**（iOS 版）。**开发者不自建支付通道、不接入任何第三方支付 SDK，不接触、也不保存你的支付信息**（卡号、账单地址等均由 Apple 处理） |
| 价格与结算 | 价格由 App Store 按地区自动换算显示，实际支付金额与币种以 App Store 结账页为准 |
| 退款 | **由 Apple 按其退款政策处理，开发者无权受理或决定退款。** 如需退款，请通过 Apple 官方「报告问题」页面（reportaproblem.apple.com）提交申请 |
| 恢复购买 | 同一 Apple ID 在换机或卸载重装后，可在 App 内使用「恢复购买」找回已购权益 |
| 跨平台边界 | **在 iOS 购买的权益无法在 Android 版恢复，Android 版的购买也无法在 iOS 恢复**——两个商店的账户与购买记录互不相通 |
| 家长门 | **购买入口位于家长锁（PIN）之后**，儿童无法自行发起购买，符合 Apple App Store 儿童类别对应用内购买的要求 |

> 说明：**本 App 不启用「家人共享」（Family Sharing）**（2026-10-19 拍板，口径 C92-1）。因此本买断权益**不随 Apple 家庭组共享**：家庭组内其他成员需用自己的 Apple ID 单独购买。如未来启用，将在此处另行说明并同步更新英文版。

## 六、数据存储与安全

- 业务数据采用 **本地加密数据库（SQLCipher）** 存储，密钥随应用安装生成、不离开设备。
- 家长 PIN 以 **sha256 + 随机 salt 哈希** 存于系统安全区（Keystore / Keychain 等价物），**不保存明文、不可反推**。
- 数据 **不上云、不同步、不备份到任何第三方服务**。应用内购买产生的付款信息由应用商店（Apple / Google）处理，我们既不接触、也不留存，且不会与你的本机数据关联。
- **卸载应用即删除全部本地数据**：加密库与键值存储随应用数据目录一并清除，不留残留。

## 十一、全球合规说明（GDPR / COPPA / 商店儿童政策）

### 11.1 GDPR（欧盟 / 欧洲经济区）

- 本 App **不收集、不上传任何个人数据**，开发者不存在以数据控制者身份进行的个人信息处理，也不存在个人信息跨境传输：你在 App 内产生的数据始终留在你的设备上。
- 由于开发者不持有你的个人数据，你**无需向开发者提出访问 / 更正 / 删除请求**即可完全掌控数据——在设备内删除数据或卸载应用，即彻底删除全部本地数据（见第六节）。
- 本政策不设置 Cookie 或类似追踪技术，不使用第三方分析工具。
- 【待定】如后续新增任何数据处理活动，将先行指定 GDPR 欧盟代表（EU Representative）并更新本节；数据控制者为**个人开发者小小葵**（见第九节）。
- 【待定】**家长 / 监护人同意机制**（GDPR 第 8 条）的具体实现与表述，待法务确认后补充。

### 11.2 COPPA（美国，13 岁以下儿童）

- 本 App 面向儿童与家庭使用，但**不收集、不请求、不上传任何儿童个人信息**：不收集姓名、邮箱、电话、位置、照片、语音等，也不提供可公开分享的用户生成内容。
- **不含任何第三方广告、行为定向广告或第三方分析 SDK**，不以任何形式基于儿童数据进行营销或画像。
- 【待定】若后续功能涉及任何儿童个人信息的收集，将改为「先取得**可验证的家长同意（VPC）**、再收集」并更新本节。

### 11.3 Apple App Store 儿童类别（Kids Category）政策（iOS，首发平台）

- 应用内**无第三方广告、无第三方分析、无社交分享**；唯一的外部通信为应用内购买结算，由 Apple 处理（见第五节）。
- **应用内购买须通过家长门（PIN）**；购买为一次性买断、非订阅、不自动续费。
- 本政策关于「不收集数据」的口径，须与 App Store Connect「App 隐私」申报逐项保持一致（本 App 申报为**不收集数据**）。

### 11.4 Google Play Families 政策（Android 版适用，未来上架时）

- Android 版上架时适用 Google Play Families 政策与 Google Play「数据安全」表单；权限口径见第四节（`INTERNET` / `ACCESS_NETWORK_STATE` / `BILLING` 均由依赖库自动合并引入，**仅用于应用内购买结算，不用于上传用户数据**）。
