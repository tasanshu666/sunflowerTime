## 1. 工具链 / 环境

| # | 经验 | 影响 | 建议（SOP 化） |
|---|---|---|---|
| E1 | **`flutter test` 在本沙箱不可用**：`flutter_tester` 进程 WebSocket 升级失败（`WebSocketException: Invalid WebSocket upgrade request`），无法加载任何测试。 | 纯逻辑单测跑不起来，CI 思路受阻。 | 纯逻辑/Domain 层单测改用 **`dart test`**：dev 依赖加 `test: ^1.24.0`，import 用 `package:test/test.dart`，而非 `flutter_test`。UI/Widget 测试仍依赖真机。 |
| E2 | ~~本机无 JDK / 无 Android SDK~~ → **⚠️ 此结论已被证伪（批次二纠正）**：本机 `java -version` 报错只是因为 JVM **不在 PATH**，而 Flutter 用的是 **Android Studio 自带 JBR**（`/Applications/Android Studio.app/Contents/jbr/.../java`），`flutter build apk` 完全正常；adb 在 `~/Library/Android/sdk/platform-tools/adb`（同样只是没进 PATH）。 | 曾据此误判"打不了 APK"，绕了远路。 | **以 `flutter doctor -v` 的 "Java binary at:" 行为准**，不要用 `java -version` 判断；adb 一律用绝对路径。详见技能 `flutter-android-apk-build`。 |
| E3 | **设备库 API 随解析版本漂移**：`native_device_orientation` 文档写 `^2.0.0`，本机实际解析 `2.1.3`，API 已变——`onOrientationChanged` 变成了**方法**（需加 `()`），且枚举**无 `portraitUpDown`**。 | 按文档写会编译失败。 | 设备库/插件 API **必须按本机 `pub get` 后实际解析版本核对**，不只读文档；以 `dart analyze` 报错为准快速收敛。 |
| E15 | **pub 归档下载被限速，`pub get` 会"假死"**：pub.dev API 返回 200，但 `tar.gz` 归档 20s 拉不完 → `flutter pub get` 跑 20 分钟无输出后被 SIGTERM(137)；`curl` 直连同样慢（3m14s 才拿到 16.9MB 的 `drift`）。 | 新依赖装不上，M0 一度卡死。 | ① 先用 `ls ~/.pub-cache/hosted/pub.dev/` 确认**到底缺哪个包**（多数依赖早已缓存）；② 用 `curl -sL --max-time 300` 单独把那一个包下下来；③ `tar -xzf` 解包进 `~/.pub-cache/hosted/pub.dev/<pkg>-<ver>/`；④ `flutter pub get --offline` 秒过。详见技能 `flutter-offline-pub-cache`。 |
| E16 | **`afterEvaluate` 的书写位置决定成败**：给全部 Android 子模块统一抬 `compileSdk` 时，覆盖块必须放在 `evaluationDependsOn(":app")` **之前**；放后面报 `Cannot run Project.afterEvaluate(Action) when the project is already evaluated`。改用 `plugins.withId("com.android.library")` 会因 android 扩展尚未创建而**静默失效**（不报错但不生效）。 | 连试 3 次才生效。 | 覆盖 Android 插件编译配置时，用 `afterEvaluate` 且置于 `evaluationDependsOn` 之前，并加 `println` 自证生效。 |
| E17 | **多次失败构建会留脏产物**：编译中途反复改 compileSdk/hook 配置后，出现 `找不到符号 类 PackageInfoPlugin` 这类"类明明在却找不到"的玄学报错。 | 排查耗时。 | 构建配置改动后用 `flutter clean` + `pub get` + 重建；报"找不到符号"先怀疑脏产物。 |
| E18 | **git push 走 HTTPS 无凭证、SSH 可用**：本机 HTTPS 推不动（卡认证），`~/.ssh/id_ed25519` 已注册 GitHub 且 `ssh -T git@github.com` 认证通过。 | 推送阻塞。 | `git remote set-url origin git@github.com:tasanshu666/sunflowerTime.git`，统一用 SSH。 |

| E19 | **`sqlite3` 3.x 已移除 `open.overrideFor` / `OperatingSystem`**：网上（含包 README）流传的 `open.overrideFor(OperatingSystem.android, openCipherOnAndroid)` 写法在本版本**已不存在**，照抄会编译失败。 | 按旧文档接 SQLCipher 会走死路。 | SQLCipher 接线以 **hook 配置**为准：`pubspec.yaml` 的 `hooks.user_defines.sqlite3: { source: system, name_android: sqlcipher }`。 |

## 3. 业务口径 / 设计

| # | 经验 | 影响 | 建议 |
|---|---|---|---|
| E8 | **C5「天花板」与「候选阈值」是两回事**：单笔候选 `130/50` 不是放行边界；实际边界是 `min(固定天花板 100/40, 月池×25%)`。早期误把 130/50 当放行线，单测全错。 | S2 判定错误、单测返工。 | 实现与单测严格以公式 `min(100/40, 池×25%)` 为放行边界；候选阈值只用于"单笔价"一档。 |
| E9 | **漏"整体池余量"闸会超额放行**：仅判月度自动子限额时，家长已核销（used）占满池后仍能自动放行。 | 超额 bug。 | C5 ② 必须双闸：`withinMonthlyCap`(autoReleased) **且** `withinPool`(used+autoReleased)。已补。 |
| E10 | **参数单点纪律（C3）真实价值**：`kPlaceMinMinutes=5 / kValidFocusMinutes=15 / kCompletionRateThreshold=0.90` 三常量"不互引、不裸字面量"，落地后 grep 巡检零漂移。 | 防孪生常量。 | 全仓数字一律引用 `prd_params.dart` / `app_constants.dart`，里程碑收尾按 §7 清单 grep。 |
| E11 | **计时用墙钟差而非 tick**：`DateTime.now().difference(_startTime)`，灭屏恢复不漂移；竖屏暂停时回拨 `_startTime -= _elapsed`。 | 满足 C3 计时不漂移验收。 | 专注计时禁用后台 tick 计数，统一墙钟差。 |
| E12 | **C5 正文与公式冲突**：正文"池=200 低年段 20"，公式 `min(40, 200×25%)=40` 给 40。 | 实现抉择。 | 已由玄参大人裁定：**按公式取 40**，正文"20"系笔误。 |
| E21 | **打盹屏退出路径已有定论，不必自造**：架构 §1.3 写明「竖屏动作（**物理竖屏 OR 手动退出**）→ 触发暂停+确认」，验证计划亦列「退出路径写死（竖屏确认/无操作区/回归首帧欢迎）」。 | 避免重复请示。 | 实现"退出"相关行为前先 grep 架构 §1.3 / 验证计划 DoD，能直接落地的不再另立口径。 |

## 4. 交互 / 导航（批次二新增）

| # | 经验 | 影响 | 建议 |
|---|---|---|---|
| E22 | **`go_router` 的 `go` 是「替换栈」不是「入栈」**——凡用 `go('/x')` 进入的页面，`/` 就**不在栈里**：AppBar 不渲染返回箭头、`Navigator.pop()` 会把最后一页弹掉（**黑屏**）、系统返回键直接退出 App。本项目连踩三次（B19 家长端 / B20 打盹屏 / B21 S1 页）。 | 三次真机 bug。 | 判据：**只要进入用 `go`，就必须显式提供返回入口**。普通页 AppBar 加 `leading → context.go('/')`；独占屏用 `PopScope(canPop:false)` 接管返回键 + 退出用 `context.go('/')`。需要 pop 语义时入口改 `push`。详见技能 `flutter-gorouter-orientation-pitfalls`。 |
| E23 | **`native_device_orientation` 订阅瞬间就会回调一次当前方向**（`useSensor: true` 走 `OrientationEventListener`）。竖握手机进入横屏页 → 首帧即 `portrait` → 误判为"退出意图"**立刻弹确认框**。 | 真机 bug（B18）。 | 方向判定必须「**宽限期 + 武装**」双保护：进场 3s 内忽略所有回调；且**先观察到一次横屏**（`landscapeLeft/Right`）才把竖屏当退出意图。 |
| E24 | **`onOrientationChanged()` 不传参 = 窗口模式**，读的是被 `SystemChrome` 锁死的 **UI 方向**（`getDisplay().getRotation()` + `configuration.orientation`），且依赖 `ACTION_CONFIGURATION_CHANGED` 广播——UI 锁定后广播永不触发，流只发一次初始值即静默。 | "竖屏保护失灵"（B12）。 | 物理方向检测一律 `onOrientationChanged(useSensor: true)`；UI 锁（`setPreferredOrientations`）与方向检测**互不干涉**才正确。 |
