### 2.1 已封装的可复用结论（防止后人重踩）

| 编号 | 结论 |
|---|---|
| K23 | 算式是**量**出来的，常量是**定**出来的；搞反会为让算式对上而改视觉 |
| K26 | 枚举 N 档 ⇒ 判据函数必须 N 个可达分支；判据量由实现暴露真量、测试零复算；期望值必须独立于实现（引用同常量 ⇒ 恒绿） |
| K27 | 平板倍率差：胶囊内距乘 `uiScaleOf`、chips 内距不乘 ⇒ 高度差恒 `12(s−1)`（1.6× 差 7.2）。**「等高同族」仅手机成立，已登记为已知差异，不改代码**；跨倍率稳定判据 = **顶边对齐** |
| K28 | 不许写死倍率/缩放器，一律从真实 `context` 取 `uiScaleOf` |
| — | 薄行几何真值：胶囊实体 **28** / 视觉槽 **32** / 视觉带 **32** / 命中盒 **44** / 圆角 **20**（道具按钮视觉 32 / 命中 44）。**不是「56 / 圆角 12」**，那是注释里 chips 视觉高 = 44+12 |

### 2.2 A4 最贵的坑（写在这里防复现）

`rainWaterBonusPp`（暴雨 +1pp）是**按日扁平量**。若加在 `!dayEnd.isAfter(now)` 守卫**外**，同日多次 tick（刷新 / 一键养护 / 浇水都会触发 `tickAll`）会反复累加 ⇒ **暴雨日变成 +2pp / +3pp，不报错、不红测**。必须在守卫**内**、与惩罚项同位置。
