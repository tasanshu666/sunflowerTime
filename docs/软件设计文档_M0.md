## 3. 分层与依赖方向

```
presentation  →  domain  ←  data
      ↓                        ↓
    core（常量 / 工具 / DI 装配）
```

- **domain 层零 Flutter 依赖**：实体与 Repository 均为纯 Dart，可被 `dart test` 直接测试（本机 `flutter test` 不可用，见经验表 E1）。
- **data 层依赖 domain**（实现其接口），**domain 不反向依赖 data**——为后续「账号 + 云同步」留口（架构 §2.1）。
- **presentation 通过 Riverpod Provider 拿 Repository**，不直接触碰 Drift/存储。

## 4. 启动链

```dart
// main.dart
Future<void> main() async {
  await bootstrap();      // WidgetsFlutterBinding + shared_preferences 预热
  runApp(const ProviderScope(child: SunFocusApp()));
}

// app.dart
// ProviderScope → MaterialApp.router(theme: buildTheme(), routerConfig: ref.watch(routerProvider))
```

`sharedPreferencesProvider` 在 `bootstrap()` 阶段由 `overrideWithValue` 注入，避免各页面异步再取。

## 6. 数据层（Drift + SQLCipher）

**10 张表**（`data/local/database/tables.dart`）：

| 表 | 说明（对应架构 §3.1） |
|---|---|
| `Settings` | 全局设置（单例行，夜间边界为唯一收口值） |

| `SunlightLedgers` | 阳光账本（append-only） |
| `RewardTemplates` | 奖励模板（定价/频次上限） |

**加密打开器**（`app_database.dart`）：

## 7. 路由表（go_router）与**返回语义**

| 路径 | 页面 | 进入方式 |
|---|---|---|
| `/` | 孩子端首页 | 根 |
| `/focus` | 打盹屏（S3） | `go`（**独占屏**） |
| `/s1-demo` | 四档反馈预览（S1） | `go` |
| `/consent` | 首启同意流 | 守卫强制 |
| `/parent` | 家长端 PIN | `go` |
| `/parent/home` | 家长端首页 | `go`（登录成功后） |

**守卫**：未同意 → 强制 `/consent`；已同意访问 `/consent` → 回 `/`。

### ⚠️ 本项目最重要的导航约定（B19/B20/B21 三次真机事故定稿）

> `go_router` 的 `go` 是**替换路由栈**，不是入栈。凡用 `go('/x')` 进入的页面，`/` 就**不在栈里**：
> AppBar 不渲染返回箭头、`Navigator.pop()` 会把最后一页弹掉（**黑屏**）、系统返回键直接退出 App。

因此本工程约定：

| 页面性质 | 返回实现 |
|---|---|
| 普通子页面（S1 预览、家长端首页） | AppBar **显式** `leading` 返回箭头 → `context.go('/')` |
| 独占屏（打盹屏） | 退出用 `context.go('/')`；`PopScope(canPop: false)` 把系统返回键接管为「暂停 + 确认框」 |

禁止在 `go` 进入的页面里使用 `Navigator.pop()` 作为退出（仅用于关闭对话框）。

## 8. 方向与常亮策略（S3 打盹屏）

| 关注点 | 实现 |
|---|---|
| 常亮 | `WakelockPlus.enable()`，退出/`dispose` 时 `disable()`（P6：国产 ROM 省电策略已在小米 14 Pro 真机验证通过） |
| 锁横屏 | `SystemChrome.setPreferredOrientations([landscapeLeft, landscapeRight])` + `immersiveSticky` |
| 物理方向检测 | `onOrientationChanged(useSensor: true)` —— **必须用传感器模式**；默认窗口模式读的是被锁死的 UI 方向，会"竖屏保护失灵"（B12） |
| 防误触发 | **宽限期**（`kOrientationGraceSeconds = 3`，抑制订阅首帧回调与进场抖动）+ **武装条件**（须先观察到一次横屏，竖屏才算退出意图）（B18） |
| 退出意图统一入口 | `_requestExit()`：物理竖屏与系统返回键**共用**，行为一致（暂停 + 确认框），依据架构 §1.3 |
| 计时 | **墙钟差**：`DateTime.now().difference(_startTime)`，灭屏不漂移；暂停恢复时回拨 `_startTime -= _elapsed`，暂停期间不计入 |
| 退出复位 | `_restoreSystemChrome()`：关常亮、解锁方向、恢复系统 UI（`_finish` 与 `dispose` 双保险） |

## 9. 家长端 PIN 与首启同意流

- **PIN 锁**（架构 §4.9 / §10.4）：本地 PIN，不接短信验证码（Plan B「无账号/无云」）。
  `SecureStore` 以 `sha256(salt + pin)` 存系统安全区；首进为「设置并进入」，之后为「校验进入」（`pinSetupProvider` 驱动双态）。
- **退出路径**：家长端首页 AppBar 返回箭头 → 孩子端；`PopScope` 拦系统返回键（否则栈底返回直接退 App）→ 同样回孩子端。
- **首启同意流**（G0 合规）：`ConsentPage` + 路由守卫；同意标记存 `settings_store`（`kPrefFirstLaunchConsented`）。
