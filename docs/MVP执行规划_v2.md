## 4. 第一批任务：三个 spike（当前唯一任务）

> 目标不是交付功能，是**量出真实小时产出**。每个 spike 完成后必须回报三段耗时。

### S1 · 四档反馈 + 向日葵画布最小实现（原 T08）

- **产出**：一屏 demo，四档反馈可切换；一个 CustomPainter 绘制的向日葵
- **记录**：AI 生成耗时 / 人工介入耗时 / 真机调试耗时
- **验收**：真机上四档切换无卡顿；向日葵绘制帧率达标
- **引用裁定**：C7

### S2 · 兑换服务纯逻辑（原 T13）

- **产出**：兑换申请状态机（pending / queued / verified）+ 免确认双条件判定函数
- **记录**：三段耗时同上
- **验收**：免确认双条件与月度池上限公式完全符合 C5；有单元测试覆盖边界
- **引用裁定**：C5

### S3 · 打盹屏专注页最小实现（原 T09）

- **产出**：横屏打盹屏 + 计时 + 常亮保持 + 方向锁
- **记录**：三段耗时同上
- **同步实测**：在 3–5 台真机（华为 / 小米 / OPPO / vivo 各尽量一台）连续跑 30–60 分钟，记录常亮是否被系统杀掉
- **验收**：常亮稳定；计时在灭屏恢复后不漂移
- **引用裁定**：C3、C7

> 三个 spike 完成后，产出一份「真实小时产出」数据。本文件据此更新 §5 排期，然后才开 M0。
