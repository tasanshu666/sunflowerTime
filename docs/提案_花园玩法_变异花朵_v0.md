# 提案 · 花园玩法扩展：变异花朵（v0，玄参已拍板方案，待上架后下一版本开发）

> 来源：玄参 2026-10-23 口述规划，「帮我先记录下来」。**玄参 2026-10-23 拍板：提案认可，先保存，待上架后在下一个版本开发**（§四开放问题实现前逐项过）。
> 排期：上架后下一版本（新增美术资产 + DB 迁移，体量 ≥ 一个 F 批次）。

## 一、玄参原话（需求记录）

> 后续的花园玩法规划：打算扩充一些植物，每个植物在**开花的时候有 10% 的概率开出变异的花朵**；变异的花朵可以：
> 1. 保持**更长的花期**；
> 2. **每日更多的晨露**；
> 3. 作为**收集图鉴**（收集向）；
> 4. 做自己的**头像**（**只有开出变异才可以**）；
> 5. 或者再增加其他属性。

## 二、主理人初评（可做，挂点基本齐全）

**总评：✅ 设定成立，与现有体系咬合度高**——纯正反馈收集向，不碰防沉迷/经济红线；且四大挂点里三个已存在：

| 玄参诉求 | 现有挂点 | 增量评估 |
|---|---|---|
| 开花 10% 概率变异 | 开花瞬间结算已有惊喜系统（保底 6☀ + 大额阳光/碎片/种子概率惊喜，`kBloomReward*` 段） | 变异建议**独立 roll**，不挤占现有惊喜概率池（否则要重调全套概率） |
| 更长花期 | 花期/复开花节奏参数已常量化（普通 14/7 天、精品 21/11 天） | 变异系数常量（如 ×1.5），数值待拍板 |
| 每日更多晨露 | 48h 晨露 `kBloomRewardDelayHours` + `dewSunlightOf`（称号加成加在折损之后） | 变异晨露倍率常量；⚠️ 等于变相加阳光产出，需与 40 级经济通盘核（见 §四.3） |
| 收集图鉴 | 图鉴=选种卡翻面（`species_lore_l10n.dart` 6 物种 14 key）；精品已有 `UnlockedSpecies` 表 | 变异形态需新解锁记录（建议 `UnlockedSpecies` 扩 variant 维度或新表，见 §四.1） |
| 做头像（仅变异可） | **头像体系现成**（`child_avatar.dart`，C90-C/C91：植物头像「种下后可选用」，存 `child_profiles.avatar` v29） | 变异头像 = 新选项类型 + 「开出过变异」资格校验——这正是「只有开出变异才可以」的现成闸门位置 |

## 三、建议的玩法口径草案（供拍板，数值全可调）

1. **变异 roll**：植物进入「盛开」瞬间判一次（每株一生一次 or 每次复开花都 roll，待拍板）；普通 10%、精英是否同率/加率（建议精英 15%，体现「精品更值」，待拍板）。
2. **变异视觉**：每物种一套变异盛开帧（豆包生成，配色/花色变异，命名 `assets/fx/grow/{物种}/mutant/frame*.webp` 走既有三级回退链）。
3. **变异权益**：花期 ×1.5 · 晨露 ×2（示例值）· 图鉴收录（变异条目单独页/角标）· 头像解锁（**唯一获取途径=开出过该物种变异**，永久资格，铲除不收回——与种子解锁同构）。
4. **「其他属性」候选**（玄参原话第 5 点，供头脑风暴，均未拍板）：
   - 变异花挂在花园里给**全花园晨露 +1**（稀有景观光环）；
   - 图鉴全收集（6 物种变异集齐）→ 称号徽章/专属嘉奖（接 C74 称号体系）；
   - 变异花自带专属**浇水施肥折扣**（经济向，谨慎——动阳光产出/消耗平衡）。
   - 🔴 不建议：任何影响专注时长结算/护眼奖励的属性（别让收集向玩法渗透专注主循环的数值）。

## 四、实现前必须先定的问题（开放问题）

1. **数据模型**：`plants` 加 `is_mutant`（schemaVersion 迁移 + 迁移测试铁律）？还是开花时写独立 `mutant_unlocks` 表（图鉴/头像资格）+ plants 只存展示态？倾向后者（资格与实例解耦，铲除/枯死不丢资格）。
2. **图鉴形态**：变异条目进现选种卡图鉴，还是独立「变异图鉴」页？现图鉴 6 物种，扩充新植物后总量多少？（玄参「扩充一些植物」——新增物种数与变异池同批定）
3. **经济核算**：晨露 ×2 + 花期 ×1.5 → 单株生命周期阳光产出上浮约多少 %？需对照 40 级升级曲线与商店价目核一遍，防止收集向玩法变「刷钱后门」。
4. **10% 概率的体验设计**：纯随机对 6-9 岁可能挫败（「为什么别人有我没有」）——可加**保底机制**（如同物种第 N 次开花必变异），待拍板。
5. **美术资产清单**：新增植物 N 种 ×（成长帧 + 盛开帧 + 变异帧）+ 变异头像立绘——豆包提示词批量生产，工作量先估。
6. **i18n**：新物种名/传说/变异条目文案（zh+en）——可并入 B4 剩余创作类批。
