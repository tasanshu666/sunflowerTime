## 二、拍短视频（每周 1–2 条）

这件事没别人能替你做，因为出镜的是你，动机也是你的。

### 第一条脚本（约 45 秒）

| 时间 | 画面 | 台词 |
|---|---|---|
| 0–3s | 孩子写作业的背影，或你面对镜头 | 「我儿子写作业坐不住，我打算给他做个东西。」 |
| 3–12s | 旧手机 + 支架 + 画了格子的卡纸，三样同框 | 「但在写代码之前，我先做了件更笨的事。」 |
| 12–25s | 孩子把手机横过来放好，专注，然后自己盖章 | 「一个旧手机，一个支架，一张卡纸。他每专注五分钟，就自己盖一个章。」 |
| 25–40s | 卡纸特写 | 「因为我不想花五个月把 App 做出来，才发现孩子根本不愿意把手机横着放在桌上。」 |
| 40–50s | 面对镜头 | 「接下来我打算找十个家长一起试。想看结果的，评论区或者私信我。」 |

**要点**：旧手机、支架、卡纸三样必须同框。孩子可以只拍手和背影。前 3 秒的钩子是「我儿子坐不住」，这个痛点自带共鸣，不需要技巧。

**发布后**：留意评论和私信。有人来问就是招募信号，拉进一个小群。

## 三、观察自家娃（每天 1 分钟，连续 7–14 天）

每天记七项，记在手机备忘录里就够：

1. 今天横屏放置几次（每次 ≥5 分钟算一次）
2. 单次最长多少分钟
3. 是孩子主动，还是你提醒
4. 盖章那一刻他的反应（**拿手机拍下来**，这是素材）
5. 有没有中断，因为什么
6. 手机烫不烫、掉电快不快
7. 你自己花了几分钟

**要提醒你的**：孩子会因为「爸爸在做这件事」而格外配合。所以第 3 项「主动还是提醒」，写报告时要打折看，不然会被自己的样本骗了。

**加测**：家里有几台旧安卓机就找几台，各连续跑 30–60 分钟，看常亮会不会被系统关掉。这一步 1–2 天，能直接定掉一个技术风险。

## 三件事的关系

- 第一件：10 分钟，做完就可以不管了，workbuddy 自己跑
- 第二件：每周 1–2 条，这是长期动作，也是 Plan B 战略的另一半
- 第三件：每天 1 分钟，两周后给我结果

如果两周内一个家长都没来问，不用慌。那也是一个答案，而且是很值钱的一个：短视频到底能不能引来家长。
