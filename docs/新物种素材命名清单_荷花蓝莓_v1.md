## 0. 一句话版本

**两个物种、每个 7 张静态图 + 3 段成长帧（每段 25~27 张）+ 可选 3 个音效。**
名字里那个 `lotus` / `blueberry` 是唯一需要你记的东西——所有文件都是它拼出来的。

## 1. 两个物种的代码身份（定了就不能改）

| 中文名 | `speciesId`（代码主键） | 目录名（去掉 `species_`） |
|---|---|---|
| **荷花** | `species_lotus` | `lotus` |
| **蓝莓** | `species_blueberry` | `blueberry` |

🔴 **为什么不能改**：`speciesId` 是落库主键（植物记录里存的是它）。上线后再改等于「老数据变成未知物种」，
只能靠兜底显示「未知植物」。所以现在定死，后面只加不改。

## 3. 静态图 · 每个物种 7 张

### 3.1 文件名（把 `{x}` 换成 `lotus` 或 `blueberry`）

| # | 文件名 | 画面要求 | 用在哪 |
|---|---|---|---|
| 1 | `species_{x}_adult_bloomed.png` | 成株**盛开** | 花园成年态、图鉴封面、商店展示、确认页 |
| 2 | `species_{x}_adult.png` | 成株**未开花** | 进度未满时的成株 |
| 3 | `species_{x}_sprout.png` | 幼苗 | 第二阶段 |
| 4 | `species_{x}_sprout_wilting.png` | 幼苗**枯萎** | 缺水/缺肥警告态 |
| 5 | `species_{x}_sprout_dead.png` | 幼苗**枯死** | 死亡态 |
| 6 | `species_{x}_adult_wilting.png` | 成株**枯萎** | 同上 |
| 7 | `species_{x}_adult_dead.png` | 成株**枯死** | 同上 |

### 3.2 直接可复制的完整清单（14 行）

```
species_lotus_adult_bloomed.png
species_lotus_adult.png
species_lotus_sprout.png
species_lotus_sprout_wilting.png
species_lotus_sprout_dead.png
species_lotus_adult_wilting.png
species_lotus_adult_dead.png
species_blueberry_adult_bloomed.png
species_blueberry_adult.png
species_blueberry_sprout.png
species_blueberry_sprout_wilting.png
species_blueberry_sprout_dead.png
species_blueberry_adult_wilting.png
species_blueberry_adult_dead.png
```

### 3.3 规格（三条硬要求）

| 项 | 要求 | 为什么 |
|---|---|---|
| 格式 | **PNG、透明底** | 叠在花园背景上，白底会露白框 |
| 画布 | **1440 × 2000**（你出更大的原图也行，我跑脚本归一化） | 现有 8 物种中 7 个都是 1440×2000（向日葵是历史遗留的 1200，未重做） |
| 构图 | **盆宽 800、盆底贴画布底边（y=2000）、盆心在画布正中 x=720** | 花园格子里所有植物必须长得一样高、盆一样大，否则并排看会「有的高有的矮」 |

🔴 **同一物种的 7 张必须是同一个盆、同一位置、同一大小**，只有植物本体在变。
这是最容易翻车的一条——不同批次出的图盆会飘。

### 3.4 不用出的

- **种子图**：所有物种共用 `assets/plants/shared/shared_seed.png`，不用单独做。
- **图鉴插图**：图鉴直接用 `adult_bloomed`，不用另出。

## 4. 成长过渡帧 · 每个物种 3 段

### 4.1 命名（`frame001` 起，**三位零填充、必须连续**）

```
assets/fx/grow/lotus/seed_to_sprout/frame001.webp … frame0NN.webp
assets/fx/grow/lotus/sprout_to_adult/frame001.webp … frame0NN.webp
assets/fx/grow/lotus/adult_to_bloomed/frame001.webp … frame0NN.webp
assets/fx/grow/blueberry/seed_to_sprout/frame001.webp … frame0NN.webp
assets/fx/grow/blueberry/sprout_to_adult/frame001.webp … frame0NN.webp
assets/fx/grow/blueberry/adult_to_bloomed/frame001.webp … frame0NN.webp
```

### 4.2 规格

| 项 | 要求 | 说明 |
|---|---|---|
| 尺寸 | **720 × 720**，透明底 | 与现有 8 物种完全一致 |
| 内容 | **含盆 + 植物整体**（不是只有植物） | 播放时整帧贴上去，不含盆会「凭空多出一个盆」 |
| 格式 | **WebP q95**（先给 PNG 也行，我转） | 现有全库已转 WebP，97M→27M |
| 帧数 | **25~27 张/段**（现有实测 25/26/27 都有） | 帧数不写死，但**同一段内不许缺号跳号** |
| 时长 | 由音频常量驱动，三段都按 **4.10 秒** 播 | 帧速 = 4100ms ÷ 你给的帧数，所以 25 张或 27 张都不影响总时长 |

### 4.3 首尾帧必须对上静态图（否则播放时会「跳一下」）

| 过渡 | 首帧应 ≈ | 尾帧应 ≈ |
|---|---|---|
| `seed_to_sprout` | 一颗种子（视觉接近 `shared_seed.png`） | `species_lotus_sprout.png` |
| `sprout_to_adult` | `species_lotus_sprout.png` | `species_lotus_adult.png` |
| `adult_to_bloomed` | `species_lotus_adult.png` | `species_lotus_adult_bloomed.png` |

## 5. 音效 · 每个物种 3 段（**可选**）

```
assets/audio/sfx/grow_lotus_seed_to_sprout.mp3
assets/audio/sfx/grow_lotus_sprout_to_adult.mp3
assets/audio/sfx/grow_lotus_adult_to_bloomed.mp3
assets/audio/sfx/grow_blueberry_seed_to_sprout.mp3
assets/audio/sfx/grow_blueberry_sprout_to_adult.mp3
assets/audio/sfx/grow_blueberry_adult_to_bloomed.mp3
```

| 项 | 要求 | 备注 |
|---|---|---|
| 时长 | **必须 4.10 秒**（4101ms） | 与现有 15 段一致，音画才同步 |
| 格式 | mp3 / 44.1kHz / 立体声 / 192kbps | — |
| 🔴 红线 | **不得短于 3 秒** | <3s 的 mp3 在 iOS 会静默失败（F77 实测，无声无日志） |
| 响度 | **不用你自己调** | 我统一归一化到 −20 LUFS（峰值封顶 −1.0） |

> **不做也可以**：没有物种专属音时，自动回退到通用音（`grow_seed_to_sprout.mp3` 那三个）。
> 结果是「有声音但不是专属的」，不影响功能。两个物种都做 = 6 段，只做一个物种也行。

## 6. 待你拍板 2 件事（影响价格与成长速度）

| # | 问题 | 选项 | 我的建议 |
|---|---|---|---|
| **Q1** | **稀有度** | 普通档：**10 碎片 或 300 阳光**，每阶段 **10 天**（不养护 30 天成株）<br>精英档：**20 碎片**，每阶段 **20 天**（60 天成株） | 荷花 → **精英**（观赏性强、出图成本高）；蓝莓 → **普通**（可食用、亲切） |
| **Q2** | **英文名** | `Lotus` / `Blueberry`，或另有偏好 | 按字面直译即可，App Store 英文区会显示 |

Q1 会决定：商店价格、成长时长、花园里并排时的定位。**给我一句「荷花精英、蓝莓普通」就行。**

## 9. 附：批量改名模板（如果你手上文件名很乱）

在素材所在目录新建 `rename.sh`，把左边的旧名替换成你的真实文件名，跑一次即可：

```bash
#!/bin/bash
# 例：荷花成株盛开
mv "IMG_0001.PNG" species_lotus_adult_bloomed.png
mv "IMG_0002.PNG" species_lotus_adult.png
mv "IMG_0003.PNG" species_lotus_sprout.png
# …按 §3.2 那 14 行继续填
```

帧序列如果是从视频抽出来的（`frame_0001.png` 之类），注意**去掉下划线**才是 `frame001` —
现有契约是 `frame001.webp`，不是 `frame_1.webp`，也不是 `frame_0001.webp`。
