## 0. 一句话结论

> **这个报错不是号码填错，是「著作权人」这个主体在系统里还没有实名认证记录。**
>
> 版权中心的著作权人**不是自由填写字段**，而是从**已认证主体库**里选。你现在是在申请表里手敲了一套信息，系统去库里查不到 → 报错 + 按钮置灰。
>
> **正确顺序：先把「机构账户」做实名认证 → 审核通过 → 回申请表，著作权人变成可选项 → 设为申请人。**

**今天能做的是「启动认证」，不是「提交申请」。** 认证审核 1–3 工作日，过了才能填表。

## 1. 报错成因（官方机制核对）

### 1.1 官方流程（版权中心《系统相关常见问答》原文）

| 步骤 | 官方原文要点 |
|---|---|
| 用户注册 | 「第三步：选择注册的账户身份」→ **个人 / 机构**（选错需重新注册，无法直接改） |
| 实名认证 | 「第一步：选择您需要办理的业务，点击【前往实名认证】」→ 完善账户信息 → 填写账户实名信息 → 提交 → 「**第四步：在账户管理界面查看实名认证审核结果**」 |
| 企业员工账户 | 「**机构管理员完成实名认证后**，进入账户管理页面，点击【添加员工账户】按钮」 |
| 实名信息变更 | 「用户中心 → 账户管理 → 实名认证 → 点击【重新认证】」 |
| 登记申请 | 「第三步：点击提交申请，提交成功前**根据申请信息可能需要进行授权验证**」 |

> 🔴 **关键**：企业员工账户的前提是「**机构管理员完成实名认证后**」——即机构本身必须先认证通过。著作权人同理。
> 🔴 **手机号 / 邮箱唯一**：一旦被当前账号占用，**无法再用于其他账号**。注册前确认你打算长期用的那个号没绑过别的账号。

### 1.2 为什么「设为申请人」是灰的

填表页这个面板的逻辑是「**查已认证主体 → 命中才允许挂到本次申请上**」。
你的账号里目前**没有**「遵化市云程智服软件技术服务部」这个已认证主体 → 命中失败 → 报错 + 按钮置灰。

### 1.3 机构实名认证要什么（官方 + 实操核对）

| # | 材料 | 具体要求 | 常见驳回原因 |
|---|---|---|---|
| 1 | 营业执照副本 | **彩色**扫描件，**平铺正角度**，边界完整、无缺失、**无反光**、**不盖章**、**无水印** | 黑白扫描 / 有反光 / 边裁掉 / 加了水印 |
| 2 | 管理员身份证正反面 | **彩色**扫描件，边界完整、无反光、无签字无盖章无水印 | 模糊 / 反光 / 缺角 |
| 3 | 授权书 | **官网下载模板**，填好后**加盖个体户公章**（委托单位盖章栏） | 未盖章 / 未用官方模板 |
| 4 | 管理员手机号 | 用于接收验证码 + 审核通知 | 号码非管理员本人 / 已被占用 |
| 5 | 管理员邮箱 | 同上 | — |
| 6 | 机构全称 | **营业执照第 1 行**（有字号的那种），不带「（个体工商户）」字样 | 与执照不一致 |
| 7 | 统一社会信用代码 | `92130281MAKRRERD1N` | 打错 |

> 📌 个体工商户的**公章**：个体户有「字号印章」，与公司公章同等效力。授权书和申请表签章页都要它 → **没有就先刻**（个体户公章几十元，当天可取）。
> 📌 授权书模板在「**账户管理 → 实名认证**」页面内下载，或官网「相关表格下载」。

### 3.1 决策建议

> **走路线 A（机构 / 其他组织）。** 理由：
> 1. **商店审核是主线** —— 你的最终目的是安卓商店上架，商店后台开发者主体 = 个体户营业执照。软著著作权人与开发者主体一致 = 零解释成本；不一致要额外举证，还可能被要求补「关系证明」。
> 2. 个体户有字号印章，授权书 + 申请表签章页本来就要盖 → 走 B 省不掉这一步，只是多免了执照和管理员身份证。
> 3. 官方填表说明明确「其他组织」类目存在且其证件类型为统一社会信用代码证 → **规则上完全站得住**。
>
> **走路线 B 的唯一理由**：个体户公章一时刻不出来，且你急着今天就把认证交上去。⚠️ 但今天也交不了（审核要 1–3 天），**公章完全来得及刻** → 建议 A。

### 3.2 ⚠️ 一个必须知道的口径分歧

坊间（多为代理机构/营销号）普遍说「个体户法律上就是经营者本人，软著应登记为**经营者个人姓名**，拿个体户执照当法人身份用——系统秒退」。

**但**：① 官方填表说明明列「其他组织」类目，定义就是「经登记并领取营业执照但不具有法人资格的组织」——个体工商户完全吻合；② 那类说法多针对**省级版权局的作品登记**（各地区口径不一），**不是中国版权保护中心的软件登记**；③ 软件登记是全国统一系统，不存在「秒退」机制，只有形式审查 + 补正。
