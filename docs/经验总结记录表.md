## 1. 工具链 / 环境

| # | 经验 | 影响 | 建议（SOP 化） |
|---|---|---|---|
| E1 | **`flutter test` 在本沙箱不可用**：`flutter_tester` 进程 WebSocket 升级失败（`WebSocketException: Invalid WebSocket upgrade request`），无法加载任何测试。 | 纯逻辑单测跑不起来，CI 思路受阻。 | 纯逻辑/Domain 层单测改用 **`dart test`**：dev 依赖加 `test: ^1.24.0`，import 用 `package:test/test.dart`，而非 `flutter_test`。UI/Widget 测试仍依赖真机。 |
| E2 | **本机无 JDK / 无 Android SDK**：`flutter build apk`、模拟器渲染均不可行。 | S1/S3 的 UI 渲染、常亮、帧率无法本地验证。 | S1/S3 的 UI/硬件相关验收必须交真机（玄参大人小米 14 Pro 等）；AI 只负责编译 + `flutter analyze` + 纯逻辑单测。 |
| E3 | **设备库 API 随解析版本漂移**：`native_device_orientation` 文档写 `^2.0.0`，本机实际解析 `2.1.3`，API 已变——`onOrientationChanged` 变成了**方法**（需加 `()`），且枚举**无 `portraitUpDown`**。 | 按文档写会编译失败。 | 设备库/插件 API **必须按本机 `pub get` 后实际解析版本核对**，不只读文档；以 `dart analyze` 报错为准快速收敛。 |

## 2. Flutter / Dart 写法

| # | 经验 | 影响 | 建议 |
|---|---|---|---|
| E4 | `withOpacity` 在新 Flutter 已弃用 → 触发 lint。 | 编译警告。 | 统一用 `withValues(alpha: 0.x)`。 |
| E5 | `Path.addEllipse` 在本版本不存在。 | 编译失败。 | 改用 `addOval(Rect.fromLTWH(...))`。 |
| E6 | 库级（文件顶部）doc comment 无 `library` 指令 → `dangling_library_doc_comments`。 | analyze info。 | 含文件级注释时，首行加 `library prd_params;` 等指令。 |
| E7 | `flutter analyze` 仅剩 12 条 info（`prefer_const_*`），无 error/warning；info 不阻断。 | 可放心交付校验。 | 验收以「无 error/warning」为通过线，info 可后续清理（如补 `const`）。 |

## 3. 业务口径 / 设计

| # | 经验 | 影响 | 建议 |
|---|---|---|---|
| E8 | **C5「天花板」与「候选阈值」是两回事**：单笔候选 `130/50` 不是放行边界；实际边界是 `min(固定天花板 100/40, 月池×25%)`。早期误把 130/50 当放行线，单测全错。 | S2 判定错误、单测返工。 | 实现与单测严格以公式 `min(100/40, 池×25%)` 为放行边界；候选阈值只用于"单笔价"一档。 |
| E9 | **漏"整体池余量"闸会超额放行**：仅判月度自动子限额时，家长已核销（used）占满池后仍能自动放行。 | 超额 bug。 | C5 ② 必须双闸：`withinMonthlyCap`(autoReleased) **且** `withinPool`(used+autoReleased)。已补。 |
| E10 | **参数单点纪律（C3）真实价值**：`kPlaceMinMinutes=5 / kValidFocusMinutes=15 / kCompletionRateThreshold=0.90` 三常量"不互引、不裸字面量"，落地后 grep 巡检零漂移。 | 防孪生常量。 | 全仓数字一律引用 `prd_params.dart`，里程碑收尾按 §7 清单 grep。 |
| E11 | **计时用墙钟差而非 tick**：`DateTime.now().difference(_startTime)`，灭屏恢复不漂移；竖屏暂停时回拨 `_startTime -= _elapsed`。 | 满足 C3 计时不漂移验收。 | 专注计时禁用后台 tick 计数，统一墙钟差。 |
| E12 | **C5 正文与公式冲突**：正文"池=200 低年段 20"，公式 `min(40, 200×25%)=40` 给 40。 | 实现抉择。 | 实现按**公式 40** 并标记待裁定；已向玄参大人发起裁定请求。 |
