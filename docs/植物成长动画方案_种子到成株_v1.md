# 植物成长动画方案 · 种子到成株 v1

> **用途**：给**用户本人**的美术制作操作指南。你用豆包等 AI 工具自己做图，工程师负责接入。
> **依据**：宪法 **C13**（画布 1200×2000 / 盆宽 800 / 盆底贴底 / 盆心 x=600）、`docs/美术资源清单_花园植物.md`、`lib/presentation/child/widgets/plant_artwork.dart`（`PlantArtCandidates` 命名契约）、`tools/normalize_plant_art.py`、`docs/动画视频提示词_豆包_v1.md`。
> **范围**：只讲「成长阶段过渡动画」怎么做，不涉及代码。

---

## 0. 当前决策：先代码，后序列帧

- **本轮（A 路线 · 纯代码动效）**：浇水、施肥等「养护动作」已用代码动效实现，**零美术成本**，先上。
- **后续（B 路线 · 序列帧 PNG）**：种子→破土、幼苗→成株等「阶段过渡」推荐使用序列帧，效果最好。
- **衔接方式**：代码动效先跑着；你做好序列帧丢进 `assets/plants/` 后，**跑一次归一化脚本即可替换**，无需改代码、无需重写下层。

> 一句话：**代码动效先上线，序列帧做好了直接丢 assets 替换。**

---

## 1. 两条技术路线说明与推荐

| 路线 | 做法 | 优点 | 缺点 | 适用 |
|---|---|---|---|---|
| **A 纯代码动效** | 用 Flutter 代码做位移/缩放/透明度补间 | 零美术成本、体积小、随时调 | 表现力有限，难做「破土抽芽」这类有机形变 | 浇水 / 施肥等小动作（本轮已做） |
| **B 序列帧 PNG** | 一过渡 = 一组 PNG，按序播放 | 表现力最强、最自然 | 需美术出图、体积大、AI 一致性差 | **成长阶段过渡（推荐）** |

**推荐**：阶段过渡走 **B**（序列帧）；日常养护小动作继续走 **A**（代码）。两者并存，互不影响。

---

## 2. 需要哪些过渡动画（清单）

> 以下为 **B 路线**要做的过渡。浇水/施肥不在表内（已走 A）。开花/枯萎为可选，按精力补。

| 过渡 | 衔接的静态图 | 建议帧数 | 单帧时长 | 循环 | 优先级 |
|---|---|---|---|---|---|
| 种子 → 破土 → 幼苗 | `seed` → `sprout` | 6–10 帧 | 80–120 ms | 否（播一次） | P0 |
| 幼苗 → 成株 | `sprout` → `adult` | 8–12 帧 | 80–120 ms | 否 | P0 |
| 开花绽放（可选） | `adult` → `adult_bloomed` | 10–14 帧 | 100–150 ms | 否 | P1 |
| 枯萎（可选） | `growing` → `wilting` | 8–10 帧 | 120–160 ms | 否 | P2 |
| 恢复（可选） | `wilting` → `growing` | 6–10 帧 | 100–150 ms | 否 | P2 |

> 总时长建议控制在 **0.8–1.5 秒**（帧数 × 单帧时长）。过渡是「状态大事件」，但仍是陪伴型，动作要缓。

## 3. 命名与规格契约（最重要 · 必须与现有系统兼容）

### 3.1 画布与盆规格（与 C13 / 归一化脚本完全一致）

| 项 | 值 | 来源 |
|---|---|---|
| 画布 | **1200 × 2000**（宽:高 = 3:5），PNG | 宪法 C13 |
| 花盆宽度 | **800 px** | C13 / `normalize_plant_art.py` |
| 花盆底部 | **贴合画布底边**（y = 2000） | C13 |
| 盆心水平位置 | **x = 600**（画布正中） | C13 |
| 背景 | 透明（见 §5 抽帧透明说明） | — |

### 3.2 序列帧命名（与静态图不冲突的独立前缀 `fx_grow_`）

```
assets/plants/fx_grow_{speciesId}_{过渡名}_{两位帧号}.png
```

- `{speciesId}`：`species_sunflower` / `species_daisy` / `species_cactus`
- `{过渡名}`：`seed_to_sprout` / `sprout_to_adult` / `adult_to_bloomed` / `wilt` / `recover`
- `{两位帧号}`：`01` `02` … `12`（零填充两位，决定播放顺序）

**完整示例（向日葵 · 种子到幼苗，10 帧）：**

```
assets/plants/fx_grow_species_sunflower_seed_to_sprout_01.png
assets/plants/fx_grow_species_sunflower_seed_to_sprout_02.png
...
assets/plants/fx_grow_species_sunflower_seed_to_sprout_10.png
```

**其它物种 / 过渡示例：**

```
assets/plants/fx_grow_species_sunflower_sprout_to_adult_01.png ... _12.png
assets/plants/fx_grow_species_sunflower_adult_to_bloomed_01.png ... _14.png
assets/plants/fx_grow_species_sunflower_wilt_01.png ... _10.png
assets/plants/fx_grow_species_sunflower_recover_01.png ... _10.png
assets/plants/fx_grow_species_daisy_seed_to_sprout_01.png ...
assets/plants/fx_grow_species_cactus_sprout_to_adult_01.png ...
```

> **为什么用 `fx_grow_` 前缀**：静态图契约是 `{speciesId}_{stage}_{status}.png`（见 `PlantArtCandidates`），序列帧用独立前缀，**不会进入五级回退、不会与静态图重名冲突**。序列帧由专属播放器按帧号顺序消费。

### 3.3 入库必做：归一化

丢进 `assets/plants/` 后，**必须跑一次**：

```bash
python3 tools/normalize_plant_art.py
```

- 脚本 glob 扫描 `assets/plants/*.png`（含 `fx_grow_*`），**统一重排为 1200×2000、盆宽 800、盆底贴底、盆心 x=600**。
- 幂等，可重复跑；原图备份到 `assets/_originals/`（不进包）。

### 3.4 帧与现有静态图的无缝衔接（关键）

过渡动画的**首帧必须≈上一阶段静态图**，**尾帧必须≈下一阶段静态图**，这样切换时盆不动、植物连续生长，没有跳变：

| 过渡 | 首帧应≈ | 尾帧应≈ |
|---|---|---|
| `seed_to_sprout` | `species_sunflower_seed.png` | `species_sunflower_sprout.png` |
| `sprout_to_adult` | `species_sunflower_sprout.png` | `species_sunflower_adult.png` |
| `adult_to_bloomed` | `species_sunflower_adult.png` | `species_sunflower_adult_bloomed.png` |
| `wilt` | `species_sunflower_adult.png`（健康） | `species_sunflower_adult_wilting.png` |
| `recover` | `species_sunflower_adult_wilting.png` | `species_sunflower_adult.png`（健康） |

> 出图时让 **盆在所有帧里同一大小、同一位置**（归一化会帮你对齐），只有植物部分在变——这是「无缝」的前提。

## 4. 豆包出图实操建议

### 4.1 风格与约束（沿用 `动画视频提示词_豆包_v1.md` 全局约束）

- 统一风格句：**粗描边、圆润造型、暖黄色系（向日葵 #FFC93C / #FFA726，盆 #E0762F，背景奶黄 #FFF3C4），平涂上色，无渐变噪点，无文字无水印。**
- 红线：是工具不是游戏，禁止「游戏/关卡/战斗/胜利/炫酷特效」；低打扰、无声为主；动作极缓。
- 关键约束（序列帧专用）：**花盆固定不动、不缩放、不跳动；背景纯色（奶黄/白/透明）；同一盆、同一机位逐帧生长。**

### 4.2 完整提示词示例（2 条，覆盖两个 P0 过渡）

**提示词 ① · 种子破土成幼苗（seed → sprout，视频生成）**

> 沿用参考图的卡通插画风格：粗描边、圆润造型、暖黄色系（向日葵 #FFC93C / #FFA726，盆 #E0762F，背景奶黄 #FFF3C4），平涂上色，无渐变噪点，无文字无水印。
> 画面中央是一只固定不动的陶土花盆（盆口宽、盆身稳，位置与大小始终完全一致），盆里是浅棕色泥土。开始是一颗埋在土里的小金种子；随后种子轻轻一动，缓缓向上顶开一小块土，嫩绿的芽尖从土里探出，接着慢慢舒展开两片小小的圆润嫩叶，叶尖极轻微颤动。整株植物从土面一点点长高，花盆始终保持同一大小、同一位置、绝不移动或缩放跳动。
> 背景为纯奶黄色、无任何其它元素，全程无镜头移动、无闪烁、无跳变，动作极缓，可作为序列帧逐帧导出。

**提示词 ② · 幼苗长成成株（sprout → adult，视频生成）**

> 沿用参考图的卡通插画风格：粗描边、圆润造型、暖黄色系（向日葵 #FFC93C / #FFA726，盆 #E0762F，背景奶黄 #FFF3C4），平涂上色，无渐变噪点，无文字无水印。
> 画面中央是同一只固定不动的陶土花盆，盆里已有一株小小的绿色向日葵幼苗（两片嫩叶、短茎）。随着时间推移，茎秆缓缓长高长粗，叶片一片片长出并舒展变大，最后在顶端渐渐鼓起一个绿色花苞。花盆大小、位置始终完全一致，绝不缩放或跳动；植物是画面里唯一生长的元素。
> 背景纯奶黄、无其它元素，全程无镜头移动、无闪烁、无跳变，动作极缓，可作为序列帧逐帧导出。

### 4.3 AI 一致性差 → 推荐「先生成视频，再抽帧」

AI 直接出序列帧**一致性差**（盆会飘、颜色会跳）。更稳的路径：

1. 用上面的提示词让豆包**生成一段短视频**（约 1 秒，对应 10 帧左右）；
2. 用 **ffmpeg 抽帧**成 PNG；
3. 抽帧后**抠掉背景变透明**，再跑归一化。

**ffmpeg 抽帧示例：**

```bash
# 种子→幼苗：目标 10 帧，画布定标 1200×2000
ffmpeg -i seed_to_sprout.mp4 -r 10 \
  -vf "scale=1200:2000:force_original_aspect_ratio=decrease,pad=1200:2000:(ow-iw)/2:(oh-ih)/2:color=0x00000000" \
  assets/plants/fx_grow_species_sunflower_seed_to_sprout_%02d.png

# 幼苗→成株：目标 12 帧
ffmpeg -i sprout_to_adult.mp4 -r 12 \
  -vf "scale=1200:2000:force_original_aspect_ratio=decrease,pad=1200:2000:(ow-iw)/2:(oh-ih)/2:color=0x00000000" \
  assets/plants/fx_grow_species_sunflower_sprout_to_adult_%02d.png

# 抽帧后务必归一化（重排盆宽/盆底/盆心，与静态图一致）
python3 tools/normalize_plant_art.py
```

> ⚠️ **透明底提醒**：视频通常无 alpha 通道，`color=0x00000000` 不会真透明。抽帧后需用抠图工具（剪映 / PS / remove.bg）把背景变透明，**再跑归一化**——否则脚本读不到「盆」的 alpha 边界，无法正确对齐。若背景保持实色，序列帧叠在花园背景上会露馅。

### 4.4 通用一致性清单（每条都影响「无缝」）

- [ ] 盆在所有帧同一大小、同一位置（归一化兜底，但出图时就尽量对齐）
- [ ] 背景纯色 / 透明，无杂项元素
- [ ] 无文字、无水印、无突然跳变
- [ ] 首尾帧分别对齐上/下阶段静态图（见 §3.4）
- [ ] 帧号零填充两位、连续、顺序即播放顺序
