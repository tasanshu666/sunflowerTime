> 范围：**T06–T10 专注闭环**（打盹屏 + 四档反馈 + 屏幕交互检测 + 阳光产出 + 结算动画）

> 产品真源：`向日葵专注_PRD_v2.0.md`；口径冲突以 `docs/口径裁定表_v1.md` 为准

## 1. 本批的产品定位

M1 交付的是**核心闭环的第一次完整跑通**：孩子从"选择时长 → 横放手机 → 专注（被花陪着）→ 到时结算拿到阳光"这条链路，第一次**端到端可跑**。

按规划，M1 完成后即具备 **G1 形态**（单户深潜 / 10 户 7 天影子测试）的条件——但**本批尚未接入任务打卡与经济闭环**，所以能观察的是"孩子愿不愿意横着放下手机、能坐多久、离席几次"，而不是留存与转化。

## 2. 用户可感知的完整路径（本批实测路径）

```
孩子端首页
   ↓ 点「开始专注」
入口页（竖屏）
   · 选时长：15 / 20 / 25 / 30 / 45 分钟（默认 20）
   · 音效 / 背景音乐开关（本批占位）
   · 引导：「把手机横过来放好」
   ↓ 点「开始专注」
打盹屏（横屏 · 低亮）
   · 顶部：本次 mm:ss / mm:ss（只留倒计时，不显示阳光数字）
   · 中央：向日葵做自己的事（呼吸式明暗，零突事件）
   · 每过 1/3 进度：送出一粒光 + 气泡「我去把它放好。」
   · 全程无按钮、无操作区
   ├─ 灭屏（把手机丢下）→ 判离席：停止产阳光
   │     · 90s → 轻声「向日葵想你了，回来看看吧」
   │     · 180s → 加重「休息一下就回来哦」
   │     · 300s → 本次专注自然结束
   ├─ 亮屏回来 → 纯视觉光晕（欢迎回来），10 秒内速率线性回满
   └─ 竖屏 / 返回键 → 「确定结束吗？」→「再坐一会」续时 或「结束」
   ↓ 到时（或主动结束）
结算页
   · 那束光从屏外飞回阳光罐，数字滚动上涨
   · 本次专注时长 / 产出阳光 / 当日累计
   · 向日葵醒着庆祝
   · 【家长转述表扬：占位，M2 夸夸台接入】
   ↓
回孩子端首页
```

## 3. 已实现的交互规则（含文档依据）

| # | 规则 | 依据 | 备注 |
|---|---|---|---|
| 1 | 在场专注 **1 阳光/分钟** | PRD §4.1.5 | — |
| 2 | **离席停止产出、不扣减已有** | PRD §4.1.5 | — |
| 3 | 恢复在场后 **10 秒线性回满**，离席窗口不补产出 | PRD §4.1.5 | 精确积分实现，实测回满得 5/60 阳光 |
| 4 | **灭屏 = 离席、停产出** | PRD §4.3 + §6.2 | ⭐ 本批用户拍板收敛的悬空项 |
| 5 | 顶部**只走本次倒计时**，不显示阳光池数字 | PRD §4.2 | — |
| 6 | 打盹屏**无任何操作区** | PRD §4.2 / §4.1.6 | 退出仅靠竖屏动作 |
| 7 | 每完成 1/3 进度送一粒光（天然 2 次） | PRD §4.1.3 | 见 §4 待确认项 1 |
| 8 | 离席 90s 轻声 / 180s 加重 / 300s 打断 | PRD §4.1.4 | 打断后阳光**全额保留** |
| 9 | 声量账：唤醒每场 ≤3 次、加重 ≤1 次 | PRD §4.1.4 | 达上限只抑制语音，时间轴照走 |
| 10 | 实际专注 **<5 分钟不产出**（主动退出与被动结束同口径） | PRD §6.2 | — |
| 11 | 竖屏 = 退出意图 → 暂停 + 确认框 | PRD §4.1.6 | — |
| 12 | 结束后**光回罐 + 账同步上涨** | PRD §4.1.2 | 表现为结算页动画 |
| 13 | 随光气泡「我去把它放好。」（只报信不夸奖） | PRD §4.1.3 三原则 | 三档无气泡、纯视觉 |

### 台词三原则的落地检查（PRD §4.1.3）

| 原则 | 落地情况 |
|---|---|
| ① 随光只报信，不夸奖 | ✅ lvl2 仅「我去把它放好。」 |
| ② 夸奖只留给真实挣来的时刻，载体分清 | ✅ 结算页是"醒着庆祝"；欢迎回来仅光晕不开口；全程唯一开口夸奖留给家长转述（M2） |
| ③ 主菜留白（任何一档不得比结算更诱人） | ✅ 四档均为轻量反馈，结算页为视觉高光 |

## 4. 与 PRD 的偏差 / 待确认项（需产品方拍板）

| # | 项 | 现状 | 待确认 |
|---|---|---|---|
| 1 | **送光基准** | 按**会话进度**（与倒计时同源）；离席期间跨 1/3 边界**仍会送光** | 是否改为"仅在场时才送"？现状下孩子不在场时会消耗一次送光名额 |
| 2 | **离席是否冻结倒计时** | **不冻结**（离席占用 planned，实际专注更少） | 是否符合"计划 20 分钟"的产品语义 |
| 3 | **时长档位** | 实现为 15/20/25/30/45 | PRD §2.1 写的是 10/15/20/25/30（本批按开发指令以 45 替换 10 档） |
| 4 | **"长时间无触摸"信号** | **关闭**（留接口） | PRD §4.3 把它列为离席信号，但 §4.2 规定打盹屏不可交互 → 两者冲突，基线缺有效输入源 |
| 5 | **唤醒/打断的补判时刻** | ticker 被 OS 挂起时，唤醒与打断在"恢复瞬间"补判 | 真机实测后确认是否影响体验与数据（孩子已回来才听到"想你了"） |

## 5. 真机验收记录（小米 14 Pro）

### 第 1 轮（⏳ 待玄参大人执行）

**验收路径与预期**：

| # | 步骤 | 预期 |
|---|---|---|
| 1 | 首页点「开始专注」→ 入口页 | 可选 15/20/25/30/45，默认 20 |
| 2 | 点「开始专注」→ 横屏进入打盹屏 | 低亮、顶部只走倒计时、无按钮 |
| 3 | 观察 1/3、2/3 进度点 | 各送出一粒光 + 气泡「我去把它放好。」 |
| 4 | **按电源键灭屏**，等约 30–60 秒，再亮屏 | 离席期间**不产阳光**；亮屏后出现欢迎光晕，速率约 10 秒回满 |
| 5 | 灭屏放置 **2 分钟以上**再亮屏 | 应依次触发轻声 → 加重唤醒文案 |
| 6 | 灭屏放置 **5 分钟以上** | 本次专注应**自然结束**（打断），已产阳光全额保留 |
| 7 | 专注中途**竖屏** | 弹「确定结束吗？」；「再坐一会」续时、「结束」进结算 |
| 8 | 横屏状态按 **Android 返回键** | 同样弹确认框（不是直接退出 App） |
| 9 | 到时自动结束 | 进结算页：光回罐动画、本次时长、产出阳光、当日累计 |
| 10 | 连跑 20–60 分钟 | 常亮是否被省电策略杀掉（P6 风险，仍需复验） |
| 11 | 进一次**不到 5 分钟**就结束 | 结算应显示**无产出**（阳光 0） |
