### 2.1 已封装的可复用结论（防止后人重踩）

| 编号 | 结论 |

| K23 | 算式是**量**出来的，常量是**定**出来的；搞反会为让算式对上而改视觉 |

| K28 | 不许写死倍率/缩放器，一律从真实 `context` 取 `uiScaleOf` |

### 2.2 A4 最贵的坑（写在这里防复现）

`rainWaterBonusPp`（暴雨 +1pp）是**按日扁平量**。若加在 `!dayEnd.isAfter(now)` 守卫**外**，同日多次 tick（刷新 / 一键养护 / 浇水都会触发 `tickAll`）会反复累加 ⇒ **暴雨日变成 +2pp / +3pp，不报错、不红测**。必须在守卫**内**、与惩罚项同位置。

### 2.5.2 可复用结论（防后人重踩）

| 编号 | 结论 |
