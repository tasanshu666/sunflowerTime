## 一、变更目标

### 1.1 产品目标（3 个，正交）

| # | 目标 | 说明 |
|---|---|---|
| G1 | **详情卡一行读懂一条属性**：删底部图例冗余区，属性短语语义化（图标 + 增减量 + 阳光图标），靠右跟行 | 信息密度降一层，孩子/家长不用对照图例反查 |

| G3 | **免费体验不降级、不误导**：免费用户全链路展示**基础值**（无 perk），金额处处与实际发放一致 | 铲除确认卡/护眼页/养护面板等金额展示**天然同源**，不出现「显示 3 发 2」式错位 |

## 二、用户故事

1. **As a** 家长，**I want** 在详情卡每行直接看到「LV1 专注小萌芽 🧿护眼 额外+1☀」，**so that** 不用查图例就知道每个称号给什么。
2. **As a** 免费版家长，**I want** 详情卡里已达等级的属性置灰带锁、点按能到购买页，**so that** 我清楚知道「再解锁什么」，并自行决定是否购买。
3. **As a** 已购买家长，**I want** 买断完成后孩子**已达到等级**的属性立即全部生效，**so that** 花钱立刻有体感（无需重新升级）。
4. **As a** 免费版的孩子，**I want** 浇水时看到的是真实扣 5☀、护眼拿的是真实 2☀，**so that** 展示与到手永远一致，不被锁住的加成误导。
5. **As a** 免费/付费任一家长，**I want** 购买页权益对比里有「称号属性」一行，**so that** 买断前就能看清这项权益。
