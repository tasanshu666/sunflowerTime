## 3. 详细描述

### 3.1 短描述（约 80 字，用于商店列表摘要）

向日葵专注是一款帮孩子练习安静专注的工具 App。孩子用专注计时赚「阳光」，在花园里养出向日葵、小雏菊、仙人掌，兑换家长设置的奖励。全程无广告、无账号、数据仅存本机，家长 PIN 守护。

### 3.2 长描述（约 400–500 字，用于商店详情页）

🌻 **向日葵专注 SunFocus** —— 陪孩子把「专注」变成一件有盼头的小事。

孩子开始一次专注，计时结束后收获「阳光」；把阳光浇灌进花园，种子会慢慢破土、抽芽、长成灿烂的向日葵、小雏菊或仙人掌。养得好，还能兑换家长提前设置好的小奖励——一次公园野餐、多讲一个睡前故事。

**为什么家长可以放心**
- 🔒 **数据全在本机**：采用本地加密数据库，无任何网络上传、无云端账号，卸载即清除。
- 🚫 **零打扰**：无广告、无第三方 SDK、无推送弹窗，孩子专注时不会被打断。
- 👨‍👩‍👧 **家长 PIN 守护**：家长端以 PIN 保护，奖励与设置只有家长能改，儿童无法自行进入。
- 🌱 **是工具不是游戏**：语言用「陪伴 / 训练 / 养成」，不制造胜负焦虑，表演式庆祝只留给专注结束那一刻。

**孩子会体验到**
- 清晰的专注计时与温柔的结算反馈；
- 一片慢慢长大的花园，三种植物各有性格；
- 浇水、施肥的日常养护，和「今天完美日」的小小骄傲。

适合在平板或手机上使用，横屏专注、竖屏经营。从今天起，和孩子一起，把专注种成一片阳光。
