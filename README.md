## 产品红线（贯穿全程）

1. 是工具，不是游戏（对外禁用「关卡 / 对战 / 玩家」等词）
2. 隐私最小必要：本地处理专注状态，不联网、不上传
3. 低打扰：无声为主、有声为辅
4. 损失可挽回：任何惩罚都留有补救路径

---

## 合规形态（Plan B）

MVP 不建账号 / 家庭组 / 云同步，主张适用《儿童个人信息网络保护规定》第 28 条豁免精神（网络侧义务归零），本地基础义务做足：隐私说明、监护人本地同意流、删除权、本地加密存储、商店页如实表述。
