# 商店截图清单（用户自截 · 小米 14 Pro）

> **用途**：交给**用户本人**的真机自截操作清单。截图由用户在小米 14 Pro 上自己截，**本清单不负责截图**。
> **应用**：向日葵专注 SunFocus ｜ 建议 **5 张** 核心屏：今日任务页 / 花园页 / 养护面板 / 商店页 / 家长端。
> **总原则**：用演示账号（假数据）截图，不要出现真实儿童姓名、真实奖励内容等隐私信息。

---

## 1. 五张截图 · 摆拍前置条件

| # | 截图屏 | 摆拍前置条件（截前先准备好） | 想突出的点 |
|---|---|---|---|
| 01 | **今日任务页** | 已完成 1–2 个专注任务，最好出现「今日完美日」标记 / 向日葵举牌庆祝态 | 专注闭环、阳光产出、成就感 |
| 02 | **花园页** | 先养出 **至少 1 株盛开植物**（`*_adult_bloomed` 态），多盆呈现不同状态（种子 / 幼苗 / 成株）；背景草地 + 左下角木牌 | 花园养成、三种植物、可玩性 |
| 03 | **养护面板** | 点开某株植物 → 弹出浇水 / 施肥面板，能看到阳光余额与进度条 | 日常养护、阳光消耗、进度反馈 |
| 04 | **商店页** | 先由**家长端**建好 **奖励模板**（如「去公园」「多讲一个故事」），且阳光数额可见 | 家长奖励兑换、目标感 |
| 05 | **家长端** | 用 PIN 进入家长中心，停在设置 / 奖励管理 / 时长统计页 | 家长 PIN 守护、管控能力 |

> 摆拍要点：截屏时**关闭系统通知 / 勿扰图标遮挡**；保持画面干净；每屏尽量只展示一个核心功能。

---

## 2. 尺寸要求（各国内商店通用 1080×1920 / 竖屏 9:16，差异见下表）

- **小米 14 Pro 原生分辨率**：3200×1440（20:9），系统截屏为 **1440×3200**。
- 提交时**裁切 / 缩放**为各商店要求比例；最接近真机又合规的是 **1080×2340（9:19.5）**，通用下限是 **1080×1920（9:16）**。
- 首图最重要（商店列表/首屏展示），建议把 **花园页（02）** 或 **今日任务页（01）** 放第一张。

| 商店 | 张数 | 推荐尺寸 | 格式 / 单张上限 | 备注 |
|---|---|---|---|---|
| 华为应用市场 | 3–5 张 | 1080×1920（或 1080×2340） | JPG/PNG，≤ 2MB | 首图最关键 |
| 小米应用商店 | 2–5 张 | 1080×1920 / 1080×2340 | PNG/JPG | 与华为口径一致 |
| OPPO 软件商店 | ≥ 3 张 | 1080×1920 | PNG/JPG | 建议 9:16 |
| vivo 应用商店 | 3–5 张 | 1080×1920 | PNG/JPG | 建议 9:16 |

> 通用建议：**竖屏 9:16，5 张覆盖核心场景**；若商店允许 1080×2340，优先用它（更贴近真机 20:9，左右不留黑边）。

## 3. 截图命名建议

按提交顺序命名，便于批量上传与核对：

```
01_今日任务页.png
02_花园页.png
03_养护面板.png
04_商店页.png
05_家长端.png
```

> 如某商店要求更多张，可在此基础上补截（如「06_植物养成中.png」「07_奖励兑换成功.png」），命名延续 `0X_场景.png` 规则。
