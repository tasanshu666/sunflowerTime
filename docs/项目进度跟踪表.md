### 花盆口径（代码事实）

`lib/presentation/child/widgets/garden_pot.dart` 里，**花盆与花在代码层就是分离的**：

```
GardenPot.build → Stack(                       // garden_pot.dart:126-151
  Positioned( bottom: potH*0.52, child: PlantArtwork(...) ),   // 花 = 图片（可换美术）
  Positioned( bottom: 0,         child: CustomPaint(_PotPainter(...)) ),  // 盆 = 自绘
)
```

| 事实 | 出处 |
|---|---|
| 花盆是**一个共用的 `_PotPainter`**，被三种格子复用（有植物 / 空盆 / 加盆位） | `garden_pot.dart:143 / 249 / 338` |
| 花盆**只有 2 个布尔参数**：`dead`（转灰）、`highlighted`（口沿橙圈）→ **实际 3 种外观** | `garden_pot.dart:372-376`、`_PotColors:34-40` |
| 花盆**无任何等级/容量视觉分级**（PRD 说的「花盆=展示权益」**代码里不存在**） | `PRD:356` vs `garden_pot.dart:372-437` |
| 花盆**不是美术资源**，是 `CustomPaint` 自绘 → 目前美术链路（`assets/plants/`）**完全不影响花盆** | `garden_pot.dart:21-22` 注释 |

→ **结论：花盆不需要「和花一起做」，也不需要按 3 物种出 3 套。** 详见本文档 §6「花盆决策建议」。

### 花盆决策建议（供 C 参考）

| 方案 | 工作量 | 得失 |
|---|---|---|
| **① 保留自绘 `_PotPainter`**（**推荐**） | 0 | 花盆是**背景道具**，27 张花才是主角；自绘盆已能表达「正常/灰死/橙警示」3 态。且自绘**小于 100 行**，改色改形很快 |
