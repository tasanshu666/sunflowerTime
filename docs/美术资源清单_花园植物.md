## 3. 阶段 × 状态：可达性矩阵（决定要出多少张）

**3 阶段**（`enums.dart:54-59`，顺序勿动）：`seed` 种子 → `sprout` 幼苗 → `adult` 成株
**4 状态**（`enums.dart:61-67`，顺序勿动）：`growing` 成长中 → `bloomed` 已开花 → `wilting` 枯萎中 → `dead` 已死亡

### 可达矩阵（每物种）

| 阶段 | growing | bloomed | wilting | dead |
|---|---|---|---|---|
| **seed** 种子 | ✅ | ❌ 不可达 | ✅ | ❌ **不可达** |
| **sprout** 幼苗 | ✅ | ❌ 不可达 | ✅ | ✅ |
| **adult** 成株 | ✅ | ✅ | ✅ | ✅ |

**可达数 = 9 / 物种 → 3 物种合计 27 张。**

### 两个「不可达」是怎么推出来的（请美术也看一眼，别白画）

**① `bloomed` 只在 `adult` 可达**
开花的唯一赋值点是 `stage == adult && progress >= 1.0`（`plant_growth_service.dart:331-338`）。种子/幼苗阶段永远不会是开花态。

**② `seed_dead` 不可达 —— 这是本轮盘点新发现的一条，容易误判**
关键：**枯萎期间植物仍在继续长大**。`_advanceGrowth`（line 245）先执行、`_applyWiltAndDeath`（line 246）后执行，而 `_advanceGrowth` **只对 `dead` 提前返回**（line 278），**不拦 `wilting`**。

推导一条「种下后完全不管」的时间线（普通人 240h/阶段 = 10 天/阶段，自动成长 10%/天）：

| 天 | 发生了什么 | 结果 |
|---|---|---|
| 0 | 种下 | `stage=seed`，`status=growing` |
| **7** | 距上次浇水满 7 天（`kPlantWiltDays=7`） | `status=wilting`，**stage 仍是 seed**（进度才 70%） |
| **10** | 进度满 1.0 → 阶段推进（**枯萎不阻止**） | `stage=sprout` |
| **14** | 枯萎已满 7 天（`kPlantDeathDays=7`） | `status=dead`，但 **stage 已经是 sprout** |

→ 死亡的时刻（第 14 天）必然晚于种子→幼苗的推进时刻（第 10 天），所以**永远见不到「种子阶段的死亡」**。
（浇水/施肥会**加快**进度，只会让它更早离开种子阶段，不可能把它锁在 seed 里等死。）

阈值常量出处：`kPlantWiltDays=7`、`kPlantDeathDays=7`（`prd_params.dart:167 / 170`）；推进循环 `plant_growth_service.dart:309-317`。

> **结论：3 张 `seed_dead` 不要出**（出了也永远看不到）。如美术求完整、想留兜底，可以出，无害但白费。

### 顺带发现的一个「美术空白」（可趁这次补上）

`seed` 阶段的 `wilting` 与 `growing` 在占位里**画得一模一样** —— `_drawSeed` 只判了 `isDead`，没判 `wilting`（`plant_artwork.dart:239-250`）。也就是说：**种子蔫了，界面上看不出来**。正式资源建议给 `seed_wilting` 一张有辨识度的图（例如种子褪色/裂开/土面干裂），否则孩子在种子期完全收不到「快救回」的视觉信号。

## 5. 图片规格要求（出图前请务必遵守）

| 项 | 要求 | 原因（出处） |
|---|---|---|
| 格式 | **PNG**（带透明通道） | 候选名硬编码 `.png`（`plant_artwork.dart:66-68`） |
| 尺寸 | 建议 **512×512**（最小 256×256） | 草地格子实际显示约 90–110px，卡片固定 44px |
| 比例 | **正方形**（1:1） | 容器是 `size × size` 方框 + `BoxFit.contain` |
| 背景 | **全透明** | 外层已有圆底色（`bg.withOpacity(0.15)`） |
| **圆形安全区** | **主体限制在居中内切圆内**，直径约为边长的 **86–88%** | 容器是圆形裁切（`BoxShape.circle` + `Clip.antiAlias`，`plant_artwork.dart:124-128`），**四角会被切掉** |
| 顶部留白 | 花瓣/顶端**至少留 6–8% 边距** | 同上，别顶到圆边 |
| 主体位置 | **水平居中、底部对齐**（根/茎基在画布下缘附近） | 植物底部落在盆口上（`garden_pot.dart:116-118`） |
| 小尺寸可辨识 | **必须在 44×44px 下仍能看出阶段与状态** | 同一张图同时用于草地（~100px）与养护卡片（固定 44px） |

### 一个容易忽略的规格：图片会随进度「缩一点」
草地里的植物会按本阶段进度做**内边距收缩**（不是放大）：

```dart
final double pad = size * growthScale * (1.0 - progress) / 2;   // plant_artwork.dart:116
```

- 草地传 `growthScale = 0.18`（`garden_pot.dart:138`）→ 进度 0 时四周各留 9% 空白、进度满时留 0
- 卡片不传（默认 `0.0`）→ 卡片里不随进度变化
- **这个收缩对正式 PNG 同样生效**（`Padding` 包在 `Image.asset` 外面，line 129-148）

→ 所以出图时**不要把主体画满整张画布**，否则进度为 0 时会被二次缩小显得更小。按上面的「内切圆 86%」构图即可自然兼容。
