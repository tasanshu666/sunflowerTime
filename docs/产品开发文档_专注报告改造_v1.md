## 1. 项目信息

- Language: 中文
- Programming Language: **Flutter + Riverpod**（沿用现有工程 `sunflower_time`，非从零新建；模板默认栈不适用）
- Project Name: `focus_report_v2`
- **原始需求复述**：① 把专注报告从「设置」里挪出来，放到**更显眼**、不「藏得深」的位置（玄参点名「记录 tab」）；② 在现有**天/周**之外，增加**月报、年报**；③ 增加**热力图**，让家长一眼看出**哪些天坚持了**；④ 报告内容「再丰富一下」。

## 2. 产品定义

### 2.1 产品目标（3 个，正交）

| # | 目标 | 判据 |
|---|---|---|
| G1 | **入口显眼**：从「设置深藏」变为一眼可见 | 报告入口落在家长端**一级可见位置**（tab 内或 tab 顶部），**≤1 次点击**到达 |
| G2 | **时间维度完整**：天/周 → 天/周/**月/年** | 报告页可切换**四档周期**（日/周/月/年），且都能看到累计分钟 + 有效专注日 |
| G3 | **坚持一眼可见**：用热力图把「坚持」可视化 | 热力图按天着色，**一眼可辨**「哪天专注了、哪天断了」、连续坚持的区间 |

### 2.2 用户故事（家长视角）

| # | 用户故事 |
|---|---|
| US-P1 | 作为家长，我想**不用进设置**就能找到孩子的专注报告，这样我随手就能看看他最近怎么样。 |
| US-P2 | 作为家长，我想看到**本月 / 今年**的专注汇总，这样我能判断孩子是长期在坚持，还是只是这几天在冲。 |
| US-P3 | 作为家长，我想看一张**热力图**，这样我一眼就能发现「哪些天断了、连续坚持了多久」。 |
| US-P4 | 作为家长，我想在报告里看到**和上期对比**（这周 vs 上周、这月 vs 上月），这样我能看出趋势是变好还是变差。 |
| US-P5 | 作为家长，我想把**周报/月报**留存或分享给家里另一位家长，这样带娃这件事不是我一个人在看。 |

## 4. 技术规范（口径，非实现）

### 4.1 数据能否从既有数据推导 —— ✅ 可以，无需改表

- **事实源 = 专注会话表**（`FocusSessions.actualFocusMin`），全部周期（日/周/月/年/热力图）均由**按日聚合**派生：`FocusRepository.sessionsOfDay(dayKey)`（现有）。
- **月** = 自然月，**年** = 自然年，**周以周一为始**（沿用 C55 记录页现有口径：半开区间 `[start, end)`）。
- **有效专注日**沿用 `focus_report_service.dart:111-117` 既有判据（不新造口径，防孪生）。
- 🔴 **不加计数列 / 不新增实体表**；`schemaVersion` 不变。

| 周期 | 派生方式 | 主要指标（建议） |
|---|---|---|
| 日 | 现有 7 日分布 | 当日分钟 / 场次 / 是否有效专注日 |
| 周 | 现有近 4 周趋势 | 本周累计分钟 / 有效专注日数 / 稳定性 |
| **月** | 遍历当月天数聚合 | 本月累计分钟 / 有效专注日数 / 平均每日 / 最好的一天 |
| **年** | 遍历当年天数聚合 | 全年累计分钟 / 有效专注日数 / **12 个月趋势** / 最长连续坚持 |
| **热力图** | 近 N 天（建议近 1 年）逐日聚合 | 每格 = 1 天，色阶按「当日专注分钟」或「是否有效专注日」 |

- ⚠️ **性能注意（留给工程判断）**：一年热力图 ≈ **365 次** `sessionsOfDay` 逐日查询。可接受与否由架构师评估；可选做法：加一个**范围查询**（如 `sessionsBetween(start,end)` 一次取回后在 Dart 内聚合）—— ⚠️ 但**给 `FocusRepository` 接口加方法会牵动全部 `implements` 实现类**（历史教训：一次加方法导致 45 个 fake 编译失败，见进度表 §1.10.8 坑①），需架构师评估代价。**本 PRD 只提口径，不指定实现。**

### 4.2 边界与口径

- **付费边界**：C69 定「免费边界 = 报告近 7 天」⇒ **月报 / 年报 / 热力图大概率归 `deepReport`（付费）**。⚠️ 是否如此、免费用户看到什么（遮罩 / 引导卡 / 只读预览），**见 §5 待确认**（不自行拍板）。
- **门控单点**：一律读 `entitlement_matrix.dart`（`FeatureKey.parentReport` / `deepReport`），**禁止页面内散写三元判断**。
- **不加等级**：家长报告**不得**出现专注等级/称号（C74 §6）。

## 5. UI 设计稿（文字描述）

### 5.1 入口（G1）

- **推荐形态**：把专注报告并入/挂到「**记录**」tab（家长端底部第 4 个 tab，图标 `Icons.history`）。两种落地候选（**待玄参拍板，见 §6-①**）：
  - **候选 A（记录 tab 内分段）**：`ParentHistoryPage` 顶部加一个 **分段控件**「专注报告 / 任务与奖励」，默认落在**专注报告**；两段共用顶部 `◀ 期间 ▶`。
  - **候选 B（报告独立成 tab）**：把底部「记录」tab 更名为「**报告**」或保留「记录」，点击后**首屏即专注报告**，任务/奖励记录下沉为子页。
- **入口卡形态（若采用 A）**：记录 tab 顶部一张**总结卡**（本周分钟 + 有效专注日 + 「查看完整报告 ›」），点卡进完整报告页。

### 5.2 报告页结构（G2 + G3）

自上而下（沿用现有 AppBar「专注报告」+ 返回键）：

1. **周期切换器**：`日 / 周 / 月 / 年` 四档 + `◀ 期间 ▶`（不翻未来，▶ 到顶禁用）—— 复用记录页 `_Period` 交互范式。
2. **主指标卡（Hero）**：本期累计专注分钟（大字）+ 副指标（有效专注日 / 稳定性或平均每日）。
3. **趋势图**：
   - 日/周 → 现有 7 日柱状图；
   - **月** → 当月每日柱状（或按周分组的 4~5 根柱）；
   - **年** → **12 个月**柱状（或折线）。
4. **热力图（热力图 P0）**：GitHub contribution 风格日历热力图。
   - 布局：**行 = 周一~周日，列 = 周**（近 1 年），或「月份 × 日」网格；
   - 色阶 **4~5 档**（建议：0 / 1–14 分钟 / 15–29 / 30–59 / ≥60；或按「有效专注日」二分）；
   - 右侧/下方**图例** + 「当前连续 N 天 / 最长 N 天」读数；
   - 点击某格 → 轻提示该日分钟数。
5. **护眼统计卡**（可随周期过滤，P2）。
6. **环比对比**（P1）：主指标卡下方一行「较上期 ▲/▼ X%」。

### 5.3 移动端 / 平板适配

- **手机**：单列纵向滚动；热力图横向可滚动（一年份格子宽度屏幕放不下）。
- **平板（834×1194，C61/C65）**：内容**限宽居中**（与家长端其他页一致）；柱状图/热力图可用更大网格；**文字走 `textScaler` ×1.3，图形元素显式乘 `uiScaleOf`**（勿双重缩放 —— 见进度表 §1.11.4 坑）。
- 深色模式：沿用 `ParentReportPage` 现有 `_ReportPalette`（深浅两套）。

## 7. 验收要点（建议，供工程与 QA 参考）

- 报告入口**≤1 次点击**可达，且**不在设置页内**（或设置页不再作为唯一入口）。
- 周期切换器含**日/周/月/年**四档；翻页不越到未来；月/年边界正确（自然月/自然年、半开区间）。
- 热力图：每格对应 1 天，色阶可辨；连续坚持读数正确。
- **数据全从会话表派生**：`schemaVersion` 不变（24），无新表/新列。
- 免费档：未解锁部分显示**引导卡**而非静默隐藏（对齐 `PremiumGate`）。
- 平板 834×1194 无溢出、无双重缩放（对齐 C65 / 进度表 §1.11.4）。
- **家长报告内零等级/称号**（C74 §6）。
