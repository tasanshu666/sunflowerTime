## 当前状态

- **阶段**：MVP 规划完成，待启动 M0 工程骨架
- **形态**：Plan B 纯本地单机（无账号 / 无家庭组 / 无云同步）；家长端本地 PIN 锁 + 同机核销；代码层预留账号 + 云同步接入点（Repository 抽象）
- **技术栈**：Flutter（MVP 先 Android）；Riverpod + Drift/SQLCipher + 原生动画 + just_audio
- **投入**：单人独立开发，兼职约 20h/周；主线构建约 18 周

## 排期（20h/周）

```
M0 骨架 → M1 专注闭环 → M2 经济商店核销(承重墙) → M3 花园任务家长端 → M4 打磨上架
                  │                              │
              G1 形态验证(10户影子测试)      G2 核心循环验证起跑(10周) ── 覆盖 M3/M4
```

- 北极星指标：WFD（周有效专注日数）≥ 4 天/周
- 主门：G2 家长核销履约率 ≥ 70%；判读于 T+22 周

## 产品红线（贯穿全程）

1. 是工具，不是游戏（对外禁用「关卡 / 对战 / 玩家」等词）
2. 隐私最小必要：本地处理专注状态，不联网、不上传
3. 低打扰：无声为主、有声为辅
4. 损失可挽回：任何惩罚都留有补救路径

## 合规形态（Plan B）

MVP 不建账号 / 家庭组 / 云同步，主张适用《儿童个人信息网络保护规定》第 28 条豁免精神（网络侧义务归零），本地基础义务做足：隐私说明、监护人本地同意流、删除权、本地加密存储、商店页如实表述。
