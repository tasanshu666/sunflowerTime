# 守卫战玩法 · 增量 PRD **v1**

> 上游依据：`docs/花园守卫_向日葵守卫者_增量PRD_v2.md`（经济红线 §3.7/§3.8 **原样继承**）
> 玄参四条裁定（2026-11）：① 15 分钟门槛不改但需说明文案；② 取消 10s 自动结算改 30s 手动战斗，怪物只偷阳光不减成长；③ 战斗表现不影响奖励，进战斗即有掉落；④ 确定性随机 seed = dayKey+childId 的 FNV-1a 派生。
> 本文只描述**相对 v1/v2 已上线版本的增量**，未提及的规则一律沿用。

---

## 1. 产品目标（一段话）

把 v1 的「44pt 胶囊 + 10 秒看动画」升级为「今日页场景卡 + 30 秒手动守卫战」：孩子用专注攒下的能量点亲手操作向日葵战士击退 3~5 只怪物，让「专注 → 能量 → 战斗 → 守护花园」的因果链**可见、可玩、可感**；同时**经济层零改动**（能量档位制：免费 1 / 完整版 2，见 §11 定稿；一天一次、5 ☀ 付费、`deriveGuardRoll` 掉落全部复用），最坏伤害封死在 ☀ 层（怪物只偷阳光、绝不碰成长数值），战斗是演出不是经济驱动的抽卡。

## 2. 用户故事（孩子视角）

1. As a 孩子, I want 在今日页看到我的花园和守在门口的向日葵战士, so that 我一眼就知道今天有贼要来、花园需要我。
2. As a 孩子, I want 看到头顶 2 个能量点点亮, so that 我明白「我刚才认真专注了 15 分钟」变成了守护花园的力量。
3. As a 孩子, I want 点「开始守卫」后亲手点按钮发射阳光弹打怪物, so that 是**我在**保护花园，而不是看一段和我无关的动画。
4. As a 孩子, I want 怪物被打败后马上看到掉落的阳光和券, so that 我的努力立刻有回报，明天还想专注攒能量。
5. As a 孩子, I want 打不完时怪物只是退走、顶多偷走几个阳光（花园植物毫发无损）, so that 我输了也不难过，不会害怕这个玩法。

## 4. 战斗规则详述（30s 手动守卫战）

### 4.1 时间轴与基本盘

| 项 | 规则 |
|---|---|
| 触发 | 点场景卡右端「开始守卫」胶囊 → 能量/付费判定沿用 v2 §3.2（免费 1⚡ / 5 ☀ / 免罚三态），确认卡后进战斗 |
| 战斗窗口 | **30 秒**（`kGuardBattleWindowMs = 30000`），从第一只怪物入场开始计时 |
| 怪物数量 | **3~5 只**，由当日确定性 seed 派生 |
| 进攻方向 | 从屏幕**左**往**右**（花园门口在右侧，战士面朝左迎敌） |
| 出怪节奏 | 由 seed 派生的固定时间表（如 0s/6s/12s/18s/24s 各出 1 只），同一天同一孩子逐位相同 |
| 闪避 | 每种怪物一个闪避参数（0~1），阳光弹命中概率 = 1 − 闪避；闪避表现为怪物小幅跳跃/侧移（轨迹由 seed 派生） |
| 结束条件 | ① 全灭 → 提前结束；② 30s 到点 → 剩余怪物**撤退**（已执行的偷窃**不回滚**，🔴 待玄参确认）；③ 孩子中途杀进程 → 回 pending 可重打 |

### 4.2 开火（交互待确认，见 §7-①）

- 主理人建议口径：**场景卡/战斗层内部的开火按钮**（大圆钮，连点即连发，冷却 ~400ms 防连点误触与可刷性）。
- 玄参原话是「点击今日页右上角的阳光漂浮胶囊」开火 —— 该区域与天气徽章/FAB 存在手势冲突风险，未获玄参明确回应，**列 P0 前置待确认项**。两者实现成本相近，确认后即可动工。

### 4.3 偷窃结算（🔴 最坏伤害封在 ☀ 层）

| 项 | 规则 |
|---|---|
| 偷窃触发 | 怪物走到花园门口未被击杀 → 偷走 **1~3 ☀**（数值由当日 seed 派生）后从右缘退场 |
| 偷窃对象 | **只扣阳光余额**，账本 1 行 `type=plant, refType='guard_stolen', net=-n`（沿用 v2 §3.6 口径）；**绝不改任何 `plant.progress` / 阶段 / `bloomedAt`** —— v2 §3.5 约束 A/B 对本玩法天然满足（无成长偷窃路径） |
| 合计封顶 | **建议：全场偷窃合计 ≤ 3 ☀**（`kGuardStealDailyCap = 3`）。全输最坏净得 = 0 ☀；正常打净得 = +1~3 ☀ + 券。🔴 **待玄参确认** |
| 血量 | 每只怪 1~3 发命中即灭（由种类定），无血条 UI（待确认见 §7-④） |

### 4.4 奖励（经济层零改动，逐条红线保留）

- **进过战斗 = 有奖励**（玄参裁定 ③）：只要进入战斗态，无论表现如何，掉落与 win 阳光照发 —— 即现有 `claim` 语义**原样复用**：必得 1~3 ☀（`deriveGuardRoll`）+ 概率掉当日券（6 档、日封顶、§3.7 三条硬约束全部不动）。
- **奖励在战斗开始前就定死**（沿用 v2 §7.3 「resolve 时掷骰」理由）：手动战斗的表现（击杀数/剩余怪/被偷量）**不影响**任何掉落字段；跳过/中断/打满 30s 的最终账本逐位相同。
- 三步幂等改造：① `resolve()` 改为「判定通过后进入战斗，战斗态不落盘」；战斗结束瞬间写入 outcome 并 `claim()`（或孩子点结算卡收取，口径随实现择一，验收要求两种路径账本一致）；② `claim()` 幂等不变；③ `expire()` 四分支（pending/fighting/claimed/short）不变。`markFighting` 的「进过战斗 ⇒ 次日不罚 + 补发」保留。

### 4.5 付费无能量路径

5 ☀ 请守卫阿葵出手：判定与账本沿用 v2 §3.2 ②。进入的战斗**是否同样手动 30s** 待确认（§7-③，主理人推荐：同样手动，代码零分叉；若玄参要「阿葵代打演出」则战斗层需要双模式，估 +1 人日）。

## 5. UI 布局描述（场景卡）

**替换对象**：今日页 `ListView` 第 0 项的 44pt 守卫胶囊（v2 §8.1）→ 高 **~120-160pt** 的守卫场景卡。
**红线**：`kTodayCardTopRatio=0.40` 等冻结三件套、等级徽章、阳光漂浮气泡、呼吸带全部不动；卡片仍在 ListView 流内，不进场景区冻结比例；窄屏（SE）按现预算滚动，回归测试覆盖既有「窄屏大字 / 呼吸带 / 徽章」用例。

```
守卫场景卡（圆角 20，与 3 张状态卡同底色系，高 120~160pt）
│
├─ L1 底图层：别墅花园场景图（通栏铺满）
│    · 左/中部 = 花园与别墅
│    · 右侧门口 = 向日葵战士站立位（idle 待机）
│
├─ L2 上空层（叠加在底图上部）
│    · 左上：2 个能量点（28pt 圆点，点亮=金色实心 / 未点亮=灰色描边）
│    · 右上：战斗中显示倒计时条（30s 递减）
│
├─ L3 交互层
│    · 右端：「开始守卫」胶囊（44pt 高，文案随三态：免费·1⚡ / 5☀ / 还差 N☀）
│    · 战斗态：胶囊位置变为场景内开火按钮（待确认 §7-①）+ 「跳过」不可用（手动战斗无跳过；
│      杀进程即视为退出，回 pending）
│
└─ L4 战斗层（点开始守卫后，在卡片内原位切换，不弹全屏对话框）
     · 怪物层：3~5 只怪从左缘依次入场，向右行走（轨迹 seed 派生 + 闪避跳动）
     · 子弹层：阳光弹从战士位置向左飞行，命中爆出小太阳粒子
     · 偷窃表现：怪物到门口 → 抱着阳光图标从右缘退场 + 余额气泡 −N
     · 收尾：全灭/到点 → 结算卡（复用 v2 §8.3，含 P1 胜利动作）
```

战斗从「全屏 dialog」改为**卡片内原位演出**：一是玄参的原始愿景就是场景卡内发生；二是规避 `showGeneralDialog` 路由栈与强杀恢复的耦合（战斗态不落盘后，卡片重建即回 pending，天然幂等）。

## 6. 「15 分钟」说明的落点与文案

| 候选位置 | 形式 | 评估 |
|---|---|---|
| A. 首次守卫教学浮层 | 首次点「开始守卫」前弹一次引导（带图示），此后可在「?」角标重看 | 信息最完整，但多一次弹窗 |
| B. 场景卡副文案 | 能量点下方一行 12sp 小字常驻 | 零交互成本，但挤占卡内空间、孩子未必读 |
| C. 能量点点按提示 | 点/长按能量点弹小气泡 | 轻量，但需要孩子主动探索才触发 |

**推荐：A 为主 + C 兜底**。教学浮层讲清楚规则（每个孩子只被教育一次），能量点点按提示作为日常 reminders，B 不采用（卡片空间紧张）。

**文案（孩子能懂，7~10 岁可读）**：

- 教学浮层主文案：**「认真专注满 15 分钟，就能攒 1 个能量点，免费一天最多攒 1 个。有能量点，向日葵战士就能免费出击，帮你赶跑偷菜的怪物！」**（B13.8 定稿：完整版一天最多 2 个，文案按档位分 `guard_intro_energy_body_free` / `guard_intro_energy_body_premium` 两套）
- 教学浮层次文案：**「没有能量点也可以花 5 个阳光请战士帮忙哦。」**
- 能量点气泡：**「专注满 15 分钟 = 1 个能量点」**（上限口径随档位，B13.8 起不再写死「每天最多 2 个」）

## 7. 待确认问题（按影响面排序，每条附主理人推荐）

| # | 问题 | 主理人推荐 |
|---|---|---|
| ① | 开火交互：玄参原案「点今日页右上角阳光漂浮胶囊」vs 场景内开火按钮？ | **场景内按钮**。右上胶囊区与天气徽章/FAB 手势冲突、且胶囊是「余额展示」语义不宜兼任开火；场景内按钮不引入新布局常量、可单测。 |
| ② | 全场偷窃是否合计封顶 3 ☀（`kGuardStealDailyCap=3`）？ | **封顶 3 ☀**。不封顶时 5 只怪全漏 = 最坏 −15 ☀，超过一次战斗 win 上限的 5 倍，负体验越线；封顶后「全输净得 0」恰好是「参战必得 1~3」的反面下界，经济闭环对称。 |
| ③ | 付费无能量路径（5 ☀ 请阿葵）是自动战斗演出还是同样手动 30s？ | **同样手动**。代码零分叉、验收一套；「阿葵代打演出」需双模式 +1 人日，且与「战斗表现不影响奖励」语义重复。 |
| ④ | 怪物是否显示血量/受击反馈？ | **不显示血条，仅受击闪白 + 1~3 发即灭**。孩子不需要读数值，闪白已足够因果反馈；血条会引入「差一点打死」的挫败精细度，与「表现不影响奖励」的心智矛盾。 |
| ⑤ | 30s 到点剩余怪物处置：撤退且已执行偷窃不回滚？ | **撤退 + 不回滚**。回滚会让「到点」变成无损等待，惩罚感消失；已偷的阳光是「没守住」的真实代价，封顶 3 ☀ 后伤害可控。 |

## 9. 不做的事（明确排除）

- **不改经济层**：能量档位制（免费 1 颗/天、完整版 2 颗/天，B13.8 定稿；初版「一律上限 2」口径作废）、一天一次、每次 1 点、5 ☀ 付费、`deriveGuardRoll` 掉落与 6 档日封顶、§3.7/§3.8 全部硬约束 —— 原样。
- **不改 `kValidFocusMinutes=15`**（WFD/统计共用口径）与 `kCompletionRateThreshold=0.90`；只加说明文案。
- **不改 `expire` 四分支**与 `kGuardSettleMaxDays=1`、免罚口径（`kGuardFreeRideBalance=5`）。
- **不做成长扣减**：怪物只偷阳光，`plant.progress` / 阶段 / 花期字段在守卫路径上零写入。
